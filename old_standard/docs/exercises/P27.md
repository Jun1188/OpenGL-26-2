## E27-01 - 세 광원이 비추는 색 재료 검사대 (A)

구 대신 서로 다른 방향의 평판 3개를 놓는다. 빨강·초록·파랑 점광원을 개별로 켜고 끈다. 표면 재질은 백색·노랑·청록이다. 광원은 각각 이동할 수 있다. 주변광과 방향광은 0이며, 정반사도 0이다. 빛과 재질의 조합에 따라 어떤 색 성분이 남는지 먼저 예측한다.

<details><summary>힌트</summary>

RGB는 성분별 곱이다. 광원 표시 객체의 색과 광원의 uniform은 서로 다른 값이다.
</details>

<details><summary>해설과 관찰 결과</summary>

각 점광원의 확산 항을 합한 뒤 재질색을 성분별로 곱한다. 백색은 세 성분을 모두 남긴다. 노랑 `(1,1,0)`은 청색 성분을 제거하고, 청록 `(0,1,1)`은 적색 성분을 제거한다. 법선이 광원을 등지면 해당 Lambert 항은 0이다.

Standard에서는 `render ambient 0 0 0`, `light sun 0`, `material target phong 0 1 0 32`를 사용한다. 광원을 선택해 `light intensity 0`으로 끈다. 광원 표시에는 unlit을 사용한다. 카메라를 움직여도 확산반사만 있는 재료의 밝기가 달라지면 실패다.

이 문제는 혼합광과 소재의 관계를 묻는다. 기존 구 3개의 배치나 C 키 순환을 재현할 필요가 없다.
</details>

## E27-02 - 이동 관찰기를 사용하는 광택 검사 (B)

곡면 물체 하나를 고정하고 관찰기가 레일을 따라 이동한다. 점광원은 고정한다. 검사 모드는 무광 `Ks=0`과 유광 `Ks=.8`이다. 유광에서 shininess를 8·32·128로 바꾼다. 무광/유광 전환이 물체의 색·텍스처·변환을 초기화하면 안 된다.

<details><summary>힌트</summary>

카메라 이동은 법선이 아니라 V를 바꾼다. 재질 전체를 기본값으로 덮기보다 기존 재질을 복사한 뒤 해당 필드만 바꾼다.
</details>

<details><summary>해설과 관찰 결과</summary>

레일의 거리에서 관찰 위치를 구하고 물체 중심을 target으로 둔다. 사용자 카메라로 직접 움직이거나 부착 카메라와 시선 규칙을 나눈다. `Material.specularStrength/shininess`만 갱신한다. `Scene::getMesh`에서 읽은 기존 재질을 복사하고 `setMaterial`로 적용하면 텍스처 상태를 유지할 수 있다.

Ks=0일 때 관찰기 이동만으로 하이라이트가 생기면 실패다. 같은 방향 오차에서 128승 값은 8승 값보다 빠르게 줄어들므로 높은 shininess의 하이라이트가 좁아진다. 광택 변화는 버텍스 수 변경과 별개다.

참조: `templates/13-phong-material.assembly`, `CameraSystem`, `Renderer::draw`의 패스별 시점 전송.
</details>

## E27-03 - 비균등 변형 천막에 붙은 조명 (C)

정점과 삼각형으로 직접 만든 천막을 사용한다. 천막은 축마다 다른 비율로 늘어나고 기울어진다. 한 지지대에는 광원이 붙는다. 광원은 지지대의 실제 위치를 따라야 하지만 표시 도형 크기는 고정한다. 천막 표면의 밝기가 비균등 배율 후에도 올바른 방향을 따라야 한다.

<details><summary>힌트</summary>

법선은 위치 벡터처럼 W로 옮기면 안 된다. 어떤 부분이 실제로 변형된 기하인지, 단순히 모델 행렬이 바뀐 것인지 구분한다.
</details>

<details><summary>해설과 관찰 결과</summary>

정점 자체를 수정하면 기하 법선을 다시 계산하고 모델의 법선 행렬도 적용한다. 정점이 그대로이고 모델 S만 바뀌면 기존 모델 법선에 역전치 행렬을 적용하면 된다. 지지대·천막 메시·광원 부착 기준을 별도 노드로 두어 배율 상속 여부를 설계한다.

지지대의 꼭대기를 모델 점 P로 저장했다면 광원 위치는 `Wsupport*P`다. 표시 크기를 고정하려면 광원의 월드 위치를 계산해 단위 크기의 별도 메시를 배치한다. 부모 비균등 배율 전체를 그대로 상속하면 표시도 늘어난다.

반사 배율에서는 삼각형 winding과 법선의 처리도 구분한다. 기본 렌더러는 행렬 determinant로 앞면 winding을 선택한다. 배율 0은 역행렬을 구할 수 없으므로 작업공간에서 허용하지 않는다. 전혀 다른 메시도 같은 VAO·법선·재질 계약으로 처리하는 것이 목표다.

참조: `Mesh::fromVertices`, `Scene::setMeshVertices/setVertexNormals`, `TransformSystem`, `Renderer::draw`.
</details>

## E27-04 - 회전 캡슐에서 분리되는 발광 탐사 입자 (C)

캡슐은 월드 Y축으로 일정하게 회전하고 원점도 이동한다. 탐사 입자는 캡슐 안의 지역 위치에서 스프링 힘을 받는다. 해제 입력 시 스프링과 부모 구속을 제거하고 월드 중력 아래로 움직인다. 입자의 표시 광원은 실제 입자 위치를 따른다. 주어진 모델은 질점이며 캡슐 벽 충돌은 요구하지 않는다.

제출: 질량·단위·스프링 강성·감쇠, 기준 프레임, 해제 시 위치와 속도 변환, 상태 전이. 미리 정한 사인 궤적으로 물리 동작을 대체하면 실패다.

<details><summary>힌트</summary>

캡슐 안의 적분 좌표와 분리 후 적분 좌표가 다르다. 분리 직전의 속도를 0으로 만들면 원래 운동이 사라진다.
</details>

<details><summary>해설과 관찰 결과</summary>

부착 상태는 `ParticleState.position/velocity`를 캡슐 지역 좌표로 저장한다. `ReferenceFrame`에 지역→월드 회전, 원점 가속도, 월드 각속도·각가속도를 넣는다. `ForceFunction`은 지역 뉴턴 단위의 스프링·감쇠 힘을 반환한다. `DynamicsSystem::step`은 중력과 이동·원심·코리올리·오일러 항을 이 힘과 합쳐 적분한다. 한 적분 경로에 같은 항을 두 번 추가하지 않는다.

해제 순간 `Pworld=O+R*r`, `Vworld=Vorigin+omega×(R*r)+R*vLocal`을 계산한다. 이후에는 월드 좌표의 별도 질점 상태를 적분하고 캡슐의 관성항을 더하지 않는다. 원점 속도는 `ReferenceFrame.acceleration`만으로 알 수 없으므로 사용자 상태로 보관한다.

광원 위치는 최종 입자 월드 위치에서 한 번 추출한다. 회전 속도 0, 원점 속도 0의 경우에는 일반 중력·스프링 운동으로 줄어들어야 한다. 해제 직전/직후 위치가 연속이어야 하며, 정지된 캡슐에서도 무조건 옆으로 튀면 속도 전달식이 잘못된 것이다.

새로운 기믹의 모델·상태 전이가 사용자 코드에 있고, 힘·좌표·그리기는 공통 API를 사용한다. 이는 강체 회전·접촉·관절 제약 솔버를 구현했다는 뜻이 아니다.
</details>
