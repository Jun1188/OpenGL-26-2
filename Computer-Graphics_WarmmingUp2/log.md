# Computer-Graphics_WarmmingUp2 솔루션 로그

이 파일은 이 솔루션에 종속된 작업 컨텍스트와 압축된 문제-해결 기록이다. 새 기록은 세션 단위로 시간순 추가한다.

## 세션 2026-09-08 13:50 KST

### 컨텍스트

- 대상: 컴퓨터 그래픽스 워밍업 2의 5번 사각형 보드와 6번 메시 파서.
- 5번 복합 크기 명령 `s/S`, `a/A`는 한 축이라도 실패하면 전체 명령을 거부한다.
- 6번 결과는 콘솔과 `outout-6/(입력파일이름-번호).txt`에 함께 기록하며 기존 파일을 덮어쓰지 않는다.

### 문제-해결

- 문제: 이동 순환으로 논리 원점이 음수가 되면 확대 경계 검사가 면제되어 `S` 반복 시 도형이 보드 전체까지 커졌다.
  - 해결: `growthCrossesBoundary()`에서 `origin < 0`인 순환 축의 확대를 경계 초과로 처리하고, 두 축을 모두 검사한 뒤 한 번만 상태를 반영했다.
- 문제: 중간 수정에서 폭 또는 높이가 1이어도 `s`의 다른 축이 부분 축소되는 잘못된 해석이 들어갔다.
  - 해결: 전체 성공/전체 거부 규칙으로 복구하고 최소 크기·일반 경계·순환 경계 테스트를 같은 규칙으로 통일했다.
- 문제: 6번은 검사 보고서를 콘솔에만 출력했다.
  - 해결: `MeshReporter`에 출력 스트림 오버로드를 추가해 보고서를 한 번 생성하고 콘솔과 자동 번호 파일에 같은 내용을 기록했다. 실행 파일에서 프로젝트 루트를 찾아 고정된 `outout-6`을 사용한다.
- 문제: 주요 오류를 한 파일에서 재현할 데이터가 없었다.
  - 해결: `data/err.txt`에 잘못된 선언, 범위 초과, 면 꼭짓점 수, 중복, 잘못된 인덱스·참조, 혼합 형식, 공선 정점을 넣었다. 실행 결과는 `outout-6/err-1.txt`에 보존했다.
- 문제: 한글 입력 파일명을 `.string()`으로 출력하면 Python UTF-8 CLI 검증이 실패했다.
  - 해결: 파일명을 `u8string()`에서 UTF-8 `std::string`으로 변환해 출력했다.

### 검증

- MSVC C++20, x64 Debug 조건, `/W4 /WX`: 빌드 성공.
- C++: 9,582 assertions, 1,500 deterministic board operations 통과.
- CLI: 실제 `x64/Debug/Computer-Graphics_WarmmingUp2.exe`로 97 checks 통과.
- `err.txt`: 종료 코드 2, `Faces: 1/10 valid; errors: 13` 확인.
- 자동 번호: 연속 실행으로 `err-1.txt`, `err-2.txt` 생성 및 동일 내용 확인. 검증용 `err-2.txt`는 제거하고 `err-1.txt`만 보존.
