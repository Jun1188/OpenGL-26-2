# 실습 17

openGL_assign_17.slnx를 Visual Studio에서 열고 Debug/Release x64로 빌드한다. C++17·v145를 사용한다. 빌드와 실행 테스트는 사용자가 수행한다.

main.cpp는 콜백을 등록하고 Console이 해당 실습의 입력·상태·장면을 관리한다. framework 폴더가 모든 외부 라이브러리를 포함한다. 프로젝트 폴더 전체를 복사하여 단독 제출할 수 있다. DLL은 실행 폴더의 framework/dependencies로 배치된다.

상세 키와 예상 결과는 저장소 docs/practice-14-19/README.md와 USER_CHECKS.md에 있다. 프레임워크 공통 응용 패턴은 framework/docs/APPLICATION_PATTERNS.md에 있다. 단독 배포 시 Console.cpp의 시작 안내와 onKey를 함께 참고한다.

### 17

1 왼쪽/2 오른쪽/3 모두를 선택한다. 초기 좌측 원뿔·우측 육면체, 위치 X ±1, 크기 배율 0.65다.

- x/X·y/Y: 로컬 양/음 자전, r/R: 원점 Y축 양/음 공전. 같은 방향 재입력은 정지한다.
- a/A: 제자리 크기 ×1.1 또는 ÷1.1. b/B: 위치와 크기를 함께 변경한다. 배율은 0.15~3으로 제한한다.
- d/D: 왼쪽/오른쪽, e/E: 위/아래. 누르는 동안 이동하고 포커스 이탈 시 해제한다.
- t: 2초 직선 교환. u: 2초 동안 한 객체는 위로, 다른 객체는 아래로 우회하여 교환한다.
- v: 두 객체가 반대 위상의 ±35% 크기 변화와 자전·공전을 한다. t/u/v 중 하나만 실행한다. 현재 위치에서 모드를 전환하며 같은 키는 정지/재개다.
- c: 두 객체의 원뿔 -> 구 -> 육면체 순환. 위치·회전·크기를 보존한다. s는 전체 초기화, q/Esc는 종료다.

개별 자전·공전과 교환은 독립 상태다. 교환이 잠시 멈춰도 개별 자전·공전을 별도로 켜 두었다면 그 동작은 계속된다. 이동·크기 명령과 활성 위치 애니메이션이 같은 값을 제어하면 위치 애니메이션이 그 프레임의 위치를 결정한다.


사용자 확인: 빌드, 조작 키, 상대경로 배포, 창 크기·최소화·포커스 이탈·종료를 직접 확인한다.
