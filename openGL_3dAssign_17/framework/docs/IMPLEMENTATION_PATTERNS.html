02. Application과 Console 연결

목적. 프레임워크 루프를 유지하고 응용 정책을 Console에 둔다.

입력 → 상태/변환 → 출력. main 객체 생성 → 콜백이 Console 호출 → run 이벤트와 렌더 진행.

#include "Console.h"

int main() {
    graphics::Application app;
    Console sample(app);

    app.setInitHandler([&](graphics::Application&) {
        return sample.initScene();
    });
    app.setKeyHandler([&](graphics::Application&, int key, int action) {
        sample.onKey(key, action);
    });
    app.setMouseHandler([&](graphics::Application&, const graphics::MouseEvent& event) {
        sample.onMouse(event);
    });

    graphics::ApplicationConfig config;
    config.title = "standard - Motion and layers";
    return app.run(config);
}

주의. 등록 시 Console 함수가 실행되는 것은 아니다. examples의 다른 main을 프로젝트에 추가하지 않는다.

사용자 확인. initScene true이면 루프 진입, Esc로 종료 요청.

03. 한 객체의 자전과 공전

목적. 같은 시계에 공전과 자전을 합성한다.

입력 → 상태/변환 → 출력. 위치 (2,0,0) → World 공전 + Local 자전 → 궤도와 물체 회전.

// init 콜백 내부. current는 Application&.
auto& scene = current.getScene();
auto& motions = scene.getMotions();
const auto object = scene.addCuboid({.4f,.6f,.3f}, {2,0,0});
graphics::RotationMotion orbit, spin;
orbit.degreesPerSecond = 20;
spin.degreesPerSecond = 90;
const auto motion = motions.createOrbitAndSpin(orbit, spin);
const auto layer = motions.pushLayer(graphics::MotionSystem::rootLayer());
if (!object || !motion || !layer) return false;
return motions.bindMotion(*layer, *motion) && scene.bindEntity(*object, *layer);

주의. createOrbitAndSpin은 World/Local을 강제한다. 축 point는 해당 공간 기준. Application의 자동 updateMotions와 중복 갱신하지 않는다.

사용자 확인. 비대칭 직육면체 중심의 공전과 자체 회전을 구분한다.

04. 경로 전환과 왕복

목적. 자전 시각을 유지하고 경로만 교체한다.

입력 → 상태/변환 → 출력. 키 → PathFunction·Playback → setMotion·seekMotion → 새 경로 0초.

// Console의 bool 함수 내부. pathId_는 기존 시계.
graphics::PathMotion path;
path.path = graphics::PathSystem::polyline({{1,-.5f,0},{2.4f,-.5f,0},{2,.6f,0}});
path.durationSeconds = 6;
path.playback = graphics::Playback::PingPong;
graphics::Motion motion;
auto& motions = app_.getScene().getMotions();
if (!pathId_ || !motion.append(graphics::Motion::followPath(path))) return false;
return motions.setMotion(*pathId_, motion) && motions.seekMotion(*pathId_, 0);

주의. setMotion은 시각을 초기화하지 않는다. 열린 경로 Loop는 끝에서 시작으로 점프. PingPong은 같은 선을 되돌아간다.

사용자 확인. 6번 경로의 왕복을 확인한다. 곡선의 매개변수 속도와 공간 이동 속도를 구분한다.

05. 순차 동작과 끝 자세 유지

목적. 유한 동작 뒤에 다음 단계를 연결한다.

입력 → 상태/변환 → 출력. 2초 이동 → then으로 1초 회전 → 앞 단계는 끝 자세 유지.

// bool 응용 함수 내부
graphics::Motion sequence;
graphics::MotionStep move;
move.durationSeconds = 2.0;
move.transform = [](double seconds) {
    return glm::translate(glm::mat4(1), glm::vec3(float(seconds),0,0));
};
graphics::RotationMotion spin;
spin.degreesPerSecond = 90;
auto turn = graphics::Motion::rotation(spin);
turn.durationSeconds = 1.0;
if (!sequence.append(move) || !sequence.then(turn)) return false;
const auto id = app_.getScene().getMotions().createMotion(sequence);
return id.has_value(); // 화면 적용에는 레이어 바인딩도 필요.

주의. 무한 단계 뒤 then은 실패. sample은 끝난 단계도 종료 시각으로 계속 평가한다. 콜백 인자는 단계 경과초다.

사용자 확인. 1초에는 이동 x=1, 3초에는 이동 x=2와 90도 Local 회전이 유지되는지 확인한다.

06. Motion 공유와 대칭 분기

두 객체가 pathId와 spinId를 공유한다. 각 시계는 레이어 수와 관계없이 한 번 갱신된다. 반사를 경로 바깥에 두어 경로와 형상을 함께 반사한다.

root (globalId: World 전체 공전, 초기 disabled)
├─ normalPath (pathId) → normalSpin (spinId) → 첫 객체
└─ mirror (반사 행렬) → mirroredPath (같은 pathId)
                       → mirroredSpin (같은 spinId) → 둘째 객체
// initScene 연결 요약. 실제 실패 처리는 14절 참조.
motions.bindMotion(*normalPath, *pathId_);
motions.bindMotion(*mirroredPath, *pathId_);
motions.bindMotion(*normalSpinLayer_, *spinId_);
motions.bindMotion(*mirroredSpin, *spinId_);

주의. YZ평면 normal=(1,0,0), Y축 직선대칭은 기본 AxisLine. 3D 직선대칭과 평면반사는 다르다. 실제 구현의 반환값 처리를 유지한다.

사용자 확인. 4번 경로에서 M으로 대칭을 바꾼다. z 좌표가 있는 경로에서 차이를 본다. 반사 없음이면 객체가 겹친다.

07. 정지와 변환 끄기

입력API결과
SpacesetMotionPlaying(id,false)시각·자세 유지, 같은 시각에서 재개.
SsetMotionEnabled(spinId,false)자전 기여 제거. playing=true이면 시각 진행.
GsetMotionEnabled(globalId,true)루트 공전 활성. 소유자 없는 선도 적용.

응용 플래그는 API 성공 뒤 변경한다. 여러 시계의 명령 전체가 자동 롤백되는 것은 아니다. standard는 실패 시 오류와 종료 요청으로 처리한다.

사용자 확인. Space 재개는 같은 위상, S 재활성화는 현재 시각의 자전인지 구분한다.

08. 바인딩을 유지하는 레이어 삽입

목적. 말단을 다시 만들지 않고 첫 객체 크기만 바꾼다.

입력 → 상태/변환 → 출력. I → 기존 말단 위 Local 크기 레이어 → 다시 I로 삭제.

// Console의 bool 함수 내부
auto& motions = app_.getScene().getMotions();
if (insertedLayer_) {
    if (!motions.removeLayer(*insertedLayer_)) return false;
    insertedLayer_.reset();
    return true;
}
const auto scale = graphics::TransformSystem::scaling(glm::vec3(1.5f));
if (!normalSpinLayer_ || !scale) return false;
graphics::LayerConfig config;
config.space = graphics::TransformSpace::Local;
config.transform = *scale;
insertedLayer_ = motions.insertLayer(*normalSpinLayer_, config);
return insertedLayer_.has_value();

주의. removeLayer는 자식 승격. 자식 있는 노드에 popLayer는 실패. 삭제 노드 자체에 객체를 묶었다면 재바인딩을 별도 설계한다.

사용자 확인. 첫 객체·부착 기저만 확대, 경로와 둘째 객체는 유지되는지 확인한다.

09. 부품 계층과 소유자 기저선

목적. 전체 자세와 부품 자세를 분리한다.

입력 → 상태/변환 → 출력. 부모 그룹 → 자식 로컬 SRT → 부품과 기저선 출력.

// init 콜백 내부
auto& scene = current.getScene();
const auto parent = scene.addGroup();
const auto part = scene.addCuboid({.6f,.2f,.3f}, {0,.4f,0});
if (!parent || !part || !scene.setParent(*part, *parent)) return false;
if (!scene.addBasis({0,0,0}, glm::mat3(1), {.5f,.5f,.5f}, *part)) return false;
graphics::Transform3D pose;
pose.basis = {1,0,0};
return scene.setTransform(*parent, pose);

주의. setParent는 월드 자세를 자동 보존하지 않는다. 부착 선 좌표는 소유자 기준. tint는 자식에 전파되지 않는다.

사용자 확인. 부모 이동 시 부품과 기저선이 함께 움직이는지 확인한다.

10. 면 힌지와 추가 로컬 행렬

목적. 객체를 유지하면서 특정 면을 회전한다.

입력 → 상태/변환 → 출력. 면·힌지 → T(pivot) R T(-pivot) → 부모 상속 면 회전.

// bool 함수 내부. id는 크기 1인 정육면체 ID.
auto& scene = app_.getScene();
graphics::AxisLine hinge;
hinge.point = {0,.5f,0};
hinge.direction = {1,0,0};
const auto matrix = graphics::TransformSystem::rotation(hinge, 45);
if (!matrix) return false;
return scene.setFaceLocalMatrix(id, 0, *matrix);

주의. 피벗은 예제 크기 전용. splitFace는 별도 엔티티를 만들지 않는다. 외부 모델의 면 번호를 가정하지 않는다.

사용자 확인. 부모를 옮겨도 열린 면이 부모를 따라가는지 확인한다.

11. 화면 위치로 객체 선택

목적. 움직임·반사와 일치하는 물체를 선택한다.

입력 → 상태/변환 → 출력. 왼쪽 PRESS 창 좌표 → DPI 환산 → 최종 행렬 삼각형 충돌.

app.setMouseHandler([](graphics::Application& current, const graphics::MouseEvent& event) {
    if (event.button != GLFW_MOUSE_BUTTON_LEFT || event.action != GLFW_PRESS) return;
    const auto hit = current.pickAt(event.windowX, event.windowY);
    if (!hit) return;
    // hit->entityId, hit->faceIndex로 응용 선택 상태를 갱신한다.
});

주의. pickAt에 framebufferX/Y를 주면 환산 중복 가능. graphics::pick은 자유 함수이고 Scene의 멤버가 아니다.

사용자 확인. 창 크기·DPI를 바꾸고 반사·공전 중 객체 위치와 선택 ID를 확인한다.

12. 메시 편집과 GPU 반영

목적. CPU 편집을 다음 렌더 업로드로 연결한다.

입력 → 상태/변환 → 출력. 조회 → 수정 값 계산 → Scene setter → revision 경로.

// bool 함수 내부. id는 유효한 모델 ID.
auto& scene = app_.getScene();
const auto* mesh = scene.getMesh(id, 0);
if (!mesh || mesh->localVertices.empty()) return false;
const glm::vec3 position = mesh->localVertices[0] + glm::vec3(0,.1f,0);
return scene.setVertexPosition(id, 0, 0, position);

주의. const를 제거해 내부 벡터를 직접 변경하지 않는다. UV 생성도 정점·인덱스를 바꿀 수 있으므로 이전 인덱스와 포인터를 재검토한다.

사용자 확인. 다음 프레임의 형상과 피킹이 함께 바뀌는지 확인한다.

13. 선택적 OBJ와 텍스처

목적. 기본 도형과 외부 자산 기능을 분리한다.

입력 → 상태/변환 → 출력. 텍스처 허용 → init에서 파일 읽기 → 피벗 보존 등록.

// main 내부. app은 Application 객체.
app.getRenderOptions().textures = true;
app.setInitHandler([](graphics::Application& current) {
    graphics::LoadOptions options;
    options.texturePath = "textures/override.png";
    options.outline = graphics::OutlineMode::FeatureEdges;
    const auto loaded = current.getAssets().loadObj("models/example.obj", options);
    if (!loaded) return false;
    return current.getScene().addModel(*loaded.model, graphics::Transform3D{},
                                     loaded.pivotMode, loaded.localBasis).has_value();
});
graphics::ApplicationConfig config;
config.features.textures = true;
return app.run(config);

주의. 파일 경로는 예제이며 해당 이름의 자산을 ZIP에 제공한다는 뜻이 아니다. 실제 파일 필요. 텍스처를 안 쓰면 texturePath와 두 텍스처 설정을 끈다.

사용자 확인. 잘못된 경로의 오류와 올바른 자산·UV의 표시를 사용자가 확인한다.

#include "Console.h"
#include <iostream>

bool Console::choosePath(int kind) {
    graphics::PathMotion path;
    path.durationSeconds = 6;
    const glm::vec3 center(1.7f, 0, 0);

    if (kind == 1) {
        path.path = graphics::PathSystem::ellipse(center, {.8f, 0, 0}, {0, .5f, 0});
    } else if (kind == 2) {
        path.path = graphics::PathSystem::rectangle(center, {.8f, 0, 0}, {0, .5f, 0});
    } else if (kind == 3) {
        path.path = graphics::PathSystem::polygon({
            {1, -.5f, 0},
            {2.4f, -.4f, 0},
            {2.1f, .6f, 0},
            {1.4f, .8f, 0},
            {.9f, .2f, 0}
        });
    } else if (kind == 4) {
        path.path = [center](double u) {
            const double angle = u * 6.283185307179586;
            return center + glm::vec3(
                float(.7 * std::sin(2 * angle)),
                float(.6 * std::sin(angle)),
                float(.3 * std::cos(angle)));
        };
        path.interpolation = graphics::PathSystem::smoothStep;
    } else if (kind == 5) {
        path.path = graphics::PathSystem::circle(center, .65f, {0, 0, 1});
    } else if (kind == 6) {
        path.path = graphics::PathSystem::polyline({
            {1, -.5f, 0},
            {2.4f, -.5f, 0},
            {2, .6f, 0}
        });
        path.playback = graphics::Playback::PingPong;
    } else {
        return false;
    }

    graphics::Motion motion;
    auto& motions = app_.getScene().getMotions();
    if (!pathId_ || !motion.append(graphics::Motion::followPath(path))) {
        return false;
    }
    if (!motions.setMotion(*pathId_, motion) || !motions.seekMotion(*pathId_, 0)) {
        return false;
    }
    std::cout << "경로 " << kind << ": 시작 시각 0초로 변경\n";
    return true;
}

bool Console::initScene() {
    auto& scene = app_.getScene();
    scene.clear();
    paused_ = false;
    spinEnabled_ = true;
    globalEnabled_ = false;
    reflection_ = 1;
    insertedLayer_.reset();

    const auto first = scene.addCuboid({.4f, .6f, .3f}, {0, 0, 0});
    const auto second = scene.addCuboid({.4f, .6f, .3f}, {0, 0, 0});
    if (!first || !second) {
        return false;
    }
    if (!scene.setTint(*first, {1, .35f, .2f})
        || !scene.setTint(*second, {.2f, .7f, 1})) {
        return false;
    }

    auto& motions = scene.getMotions();
    pathId_ = motions.createMotion(graphics::Motion{});
    graphics::RotationMotion spin;
    spin.degreesPerSecond = 90;
    spinId_ = motions.createSpin(spin);
    graphics::RotationMotion global;
    global.degreesPerSecond = 15;
    globalId_ = motions.createOrbit(global);
    if (!pathId_ || !spinId_ || !globalId_ || !choosePath(1)) {
        return false;
    }
    if (!motions.setMotionEnabled(*globalId_, false)
        || !motions.bindMotion(graphics::MotionSystem::rootLayer(), *globalId_)) {
        return false;
    }

    const auto normalPath = motions.pushLayer(graphics::MotionSystem::rootLayer());
    const auto reflection = graphics::TransformSystem::reflectPlane({0, 0, 0}, {1, 0, 0});
    if (!normalPath || !reflection) {
        return false;
    }
    graphics::LayerConfig mirror;
    mirror.transform = *reflection;
    mirrorLayer_ = motions.pushLayer(graphics::MotionSystem::rootLayer(), mirror);
    if (!mirrorLayer_) {
        return false;
    }
    const auto mirroredPath = motions.pushLayer(*mirrorLayer_);
    normalSpinLayer_ = motions.pushLayer(*normalPath);
    if (!mirroredPath || !normalSpinLayer_) {
        return false;
    }
    const auto mirroredSpin = motions.pushLayer(*mirroredPath);
    if (!mirroredSpin
        || !motions.bindMotion(*normalPath, *pathId_)
        || !motions.bindMotion(*mirroredPath, *pathId_)
        || !motions.bindMotion(*normalSpinLayer_, *spinId_)
        || !motions.bindMotion(*mirroredSpin, *spinId_)
        || !scene.bindEntity(*first, *normalSpinLayer_)
        || !scene.bindEntity(*second, *mirroredSpin)) {
        return false;
    }
    if (!scene.addBasis({0, 0, 0}, glm::mat3(1), {.55f, .55f, .55f}, *first)
        || !scene.addBasis({0, 0, 0}, glm::mat3(1), {.55f, .55f, .55f}, *second)
        || !scene.addLine({0, -1.4f, 0}, {0, 1.4f, 0}, {.5f, .5f, .5f})) {
        return false;
    }

    auto& camera = app_.getCamera();
    camera.position = {5, 3, 8};
    camera.target = {0, 0, 0};
    camera.up = {0, 1, 0};
    printHelp();
    return true;
}

bool Console::changeReflection() {
    const int next = (reflection_ + 1) % 4;
    std::optional<glm::mat4> matrix = glm::mat4(1);
    if (next == 1) {
        matrix = graphics::TransformSystem::reflectPlane({0, 0, 0}, {1, 0, 0});
    } else if (next == 2) {
        matrix = graphics::TransformSystem::reflectPoint({0, 0, 0});
    } else if (next == 3) {
        matrix = graphics::TransformSystem::reflectLine(graphics::AxisLine{});
    }
    if (!mirrorLayer_ || !matrix) {
        return false;
    }
    graphics::LayerConfig config;
    config.transform = *matrix;
    if (!app_.getScene().getMotions().setLayer(*mirrorLayer_, config)) {
        return false;
    }
    reflection_ = next;
    const char* names[] = {"없음", "YZ평면 반사", "원점 점대칭", "Y축 직선대칭"};
    std::cout << "반사: " << names[reflection_] << '\n';
    return true;
}

bool Console::toggleInsertedLayer() {
    auto& motions = app_.getScene().getMotions();
    if (insertedLayer_) {
        if (!motions.removeLayer(*insertedLayer_)) {
            return false;
        }
        insertedLayer_.reset();
        std::cout << "추가 크기 레이어 삭제\n";
        return true;
    }
    const auto scale = graphics::TransformSystem::scaling(glm::vec3(1.5f));
    if (!normalSpinLayer_ || !scale) {
        return false;
    }
    graphics::LayerConfig config;
    config.space = graphics::TransformSpace::Local;
    config.transform = *scale;
    insertedLayer_ = motions.insertLayer(*normalSpinLayer_, config);
    if (!insertedLayer_) {
        return false;
    }
    std::cout << "첫 객체에 1.5배 Local 크기 레이어 삽입\n";
    return true;
}

void Console::onKey(int key, int action) {
    if (action != GLFW_PRESS) {
        return;
    }
    auto& motions = app_.getScene().getMotions();
    bool ok = true;
    if (key == GLFW_KEY_ESCAPE) {
        app_.requestClose();
    } else if (key >= GLFW_KEY_1 && key <= GLFW_KEY_6) {
        ok = choosePath(key - GLFW_KEY_1 + 1);
    } else if (key == GLFW_KEY_SPACE) {
        const bool playing = paused_;
        ok = pathId_ && spinId_ && globalId_
            && motions.setMotionPlaying(*pathId_, playing)
            && motions.setMotionPlaying(*spinId_, playing)
            && motions.setMotionPlaying(*globalId_, playing);
        if (ok) {
            paused_ = !paused_;
            std::cout << (paused_ ? "시간 정지\n" : "시간 재개\n");
        }
    } else if (key == GLFW_KEY_S) {
        ok = spinId_ && motions.setMotionEnabled(*spinId_, !spinEnabled_);
        if (ok) {
            spinEnabled_ = !spinEnabled_;
            std::cout << "자전 기여: " << spinEnabled_ << '\n';
        }
    } else if (key == GLFW_KEY_G) {
        ok = globalId_ && motions.setMotionEnabled(*globalId_, !globalEnabled_);
        if (ok) {
            globalEnabled_ = !globalEnabled_;
            std::cout << "전체 공전 기여: " << globalEnabled_ << '\n';
        }
    } else if (key == GLFW_KEY_M) {
        ok = changeReflection();
    } else if (key == GLFW_KEY_I) {
        ok = toggleInsertedLayer();
    } else if (key == GLFW_KEY_H) {
        printHelp();
    }
    if (!ok) {
        std::cerr << "샘플 명령 적용 실패. 장면을 종료합니다.\n";
        app_.requestClose();
    }
}

void Console::onMouse(const graphics::MouseEvent& event) {
    if (event.button != GLFW_MOUSE_BUTTON_LEFT || event.action != GLFW_PRESS) {
        return;
    }
    const auto hit = app_.pickAt(event.windowX, event.windowY);
    if (hit) {
        std::cout << "entity=" << hit->entityId << " face=" << hit->faceIndex << '\n';
    }
}

void Console::printHelp() const {
    std::cout << "standard: 프레임워크 Motion·반사·레이어 샘플\n"
              << "1 타원 / 2 사각형 / 3 다각형 / 4 사용자 3D 경로+보간 / 5 원 / 6 왕복 꺾은선\n"
              << "Space 시간 정지·재개 / S 자전 기여 / G 전체 공전 기여\n"
              << "M 반사 변경 / I 크기 레이어 삽입·삭제 / H 도움말 / Esc 종료\n"
              << "초기 반사: YZ평면. M은 점대칭 -> Y축 직선대칭 -> 없음 -> YZ평면 순환\n"
              << "왼쪽 클릭: 물체의 entity/face ID 출력\n";
}

15. 공유와 사용자 확인

framework ZIP은 라이브러리, standard ZIP은 실행 프로젝트와 자체 framework를 포함한다. 각 docs에서 HTML 두 개를 연다. 스타일·목차·소스 원문은 문서 내부에 있어 인터넷 없이 읽을 수 있다.

함수 / 기능입력과 동작반환 / 실패 / 주의
보존Framework.h, include, detail, shaders, dependencies, props, 라이선스standard는 main·Console·slnx·vcxproj·내부 framework도 포함.
불필요한 로컬 파일.vs, x64 빌드 출력, vcxproj.user이번 원본은 용량 정리를 위한 삭제가 필요 없음. dependencies DLL/LIB와 모델 OBJ는 보존.
도구Windows x64, C++17, Visual Studio v145, Windows SDK 10.0다른 PC 설치 여부 미확인. Framework.props 연결.
실행 배포props는 자기 경로 기준 dependencies 탐색빌드 후 DLL·라이선스·셰이더를 EXE 옆 framework로 복사. EXE 단독 공유 불충분.
  1. 사용자가 ZIP을 원래 저장소 밖에 푼다. framework는 새 x64 프로젝트에 연결, standard는 standard.slnx를 연다.
  2. 사용자가 Debug/Release x64를 빌드한다. 실행 프로젝트의 main은 하나만 포함한다.
  3. 사용자가 창·한글·객체·기저선을 확인한다. 1~6, Space, S, G, M, I, H, Esc와 왼쪽 클릭을 확인한다.
  4. 최소화·복구·창 크기 변경과 저장소 밖 DLL 로딩을 확인한다.
  5. 브라우저에서 HTML 목차·문서 간 링크·소스 펼치기·좁은 화면·인쇄를 확인한다.

기존 설명: framework README. 이 HTML의 핵심 내용은 다른 실습 폴더 링크를 필요로 하지 않는다.

에이전트는 빌드·실행·테스트·브라우저 검증을 하지 않았다. 파일 생성·소스 대조·ZIP 용량 확인은 실행 성공과 별개다.
