지역 변환의 순서

이동한 축·회전한 축에서 다음 연산을 적용할 때

load examples/assembly/templates/01-local-order.assembly

명령어 [결과]인수·관찰점
add box item at 0 0 0기본 물체 생성
layer add turn회전 레이어 생성
layer r y 30지역 Y축으로 30도 회전
layer add offset앞 레이어의 회전된 축을 상속하는 이동 레이어 생성
layer t 2 0 0회전된 지역 X축으로 2 이동
layer add shape비균등 형상 레이어 생성
layer s 2 1 0.5지역 세 축 배율을 따로 적용
복사할 원문
# @title: 지역 변환의 순서
# @goal: 이동한 축·회전한 축에서 다음 연산을 적용할 때
#: 독립 템플릿의 시작 장면
clear
#: 관찰 카메라
camera pose 8 6 10 0 0 0 0 1 0

#: 기본 물체 생성
add box item at 0 0 0

#: 회전 레이어 생성
layer add turn

#: 지역 Y축으로 30도 회전
layer r y 30

#: 앞 레이어의 회전된 축을 상속하는 이동 레이어 생성
layer add offset

#: 회전된 지역 X축으로 2 이동
layer t 2 0 0

#: 비균등 형상 레이어 생성
layer add shape

#: 지역 세 축 배율을 따로 적용
layer s 2 1 0.5

피벗을 고정한 회전

중심·끝점·관절·임의 기준점 주위로 돌 때

load examples/assembly/templates/02-pivot.assembly

명령어 [결과]인수·관찰점
add box rod 0 0 0 4 0.2 0.2길이 4의 막대 생성
pivot rod -2 0 0 keep막대 왼쪽 끝을 피벗으로 지정하되 배치는 유지
insert spin z 45지정한 피벗 주위로 지역 Z축 자전
복사할 원문
# @title: 피벗을 고정한 회전
# @goal: 중심·끝점·관절·임의 기준점 주위로 돌 때
#: 독립 템플릿의 시작 장면
clear
#: 관찰 카메라
camera pose 8 6 10 0 0 0 0 1 0

#: 길이 4의 막대 생성
add box rod 0 0 0 4 0.2 0.2

#: 막대 왼쪽 끝을 피벗으로 지정하되 배치는 유지
pivot rod -2 0 0 keep

#: 지정한 피벗 주위로 지역 Z축 자전
insert spin z 45

월드 좌표로 부착하고 상속

서로 다른 물체가 공통 이동을 따라갈 때

load examples/assembly/templates/03-inherit-world.assembly

명령어 [결과]인수·관찰점
add joint base at 10 0 0부모 프레임을 월드 X=10에 생성
add box item at 12 0 0자식을 월드 X=12에 생성
parent base현재 월드 배치를 유지해 부모 연결
insert spin y 45자식 내부 회전 추가
select base부모 선택
t 15 0 0부모를 월드 X=15로 이동. 자식 기준 배치는 X=17
복사할 원문
# @title: 월드 좌표로 부착하고 상속
# @goal: 서로 다른 물체가 공통 이동을 따라갈 때
#: 독립 템플릿의 시작 장면
clear
#: 관찰 카메라
camera pose 8 6 10 0 0 0 0 1 0

#: 부모 프레임을 월드 X=10에 생성
add joint base at 10 0 0

#: 자식을 월드 X=12에 생성
add box item at 12 0 0

#: 현재 월드 배치를 유지해 부모 연결
parent base

#: 자식 내부 회전 추가
insert spin y 45

#: 부모 선택
select base

#: 부모를 월드 X=15로 이동. 자식 기준 배치는 X=17
t 15 0 0

명령어 [결과]인수·관찰점

# @title: 같은 변환을 조명·카메라에 사용
# @goal: 시각 객체와 관찰·광원 배치를 함께 조립할 때

#: 관찰할 물체 생성

#: 점광원 생성
