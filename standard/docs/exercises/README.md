# 새로운 상황에 적용하는 응용 N제

목표는 **처음 보는 사물과 동작 규칙을 연산·상태·시간·좌표계로 분해하는 것**이다. 실습의 형상이나 키 배치를 다시 맞히는 문제집이 아니다. 저울도 과거에 나온 전이 사례 하나다.

| 묶음 | 새 상황 | 문제 수 |
|---|---|---:|
| [P24: 기준 이동·부착·관찰](P24.md) | 회전 레일, 비행체 간 인계, 전시 장치, 수직 관찰기 | 4 |
| [P26: 독립 동작·광원·거리](P26.md) | 신축 검사 암, 가변 패널, 터널 장치, 타원 레일 | 4 |
| [P27: 재질·시점·새 규칙](P27.md) | 혼합 조명, 광택 검사기, 변형 천막, 회전 캡슐 | 4 |

현재 12문제다. 새 실습을 구현할 때 해당 요소를 기존 내용과 조합한 문제를 추가한다. 실습 25는 자료와 구현 요청이 없어 다루지 않았다.

각 문제는 요구 → 저장할 값 → 적용 공간 → 갱신 순서 → 관찰 결과를 먼저 설계한다. 힌트와 해설은 접힌 영역에 있다. 해설은 설계와 알고리즘이며 N제 12개를 완성된 실행 프로그램으로 구현한 것은 아니다. 실제 소스 참조와 실행 템플릿은 [요구사항 대응표](../PRACTICE_24_PLUS.md), [변환 템플릿](../TRANSFORM_TEMPLATES.md), [새 동작 연결](../EXTENDING_MECHANISMS.md)에 있다.

난도 A는 주어진 연산을 정확히 배치하는 문제, B는 서로 다른 연산과 상태를 조합하는 문제, C는 사용자 규칙·힘·제약 모델을 정해야 하는 문제다. 구현 전 각 문제의 관찰 결과를 스스로 예측하고, 구현 후 사용자 실행으로 비교한다.

사용할 수 없는 기능을 발견하면 특정 사물 전용 API부터 만들지 않는다. 기존 공통 연산과 사용자 콜백으로 해결되는지 보고, 반복 사용되는 최소 연산만 프레임워크에 추가한다. [조합과 확장의 경계](../EXTENDING_MECHANISMS.md)를 따른다.
