# 실습 24·26·27 요구사항 대응표

PDF의 글·그림·입력을 소스와 대조한 결과다. 아래의 반영은 **소스 작성** 상태다. 컴파일·실행·화면 확인 성공을 뜻하지 않는다. 빌드·테스트·검증기·앱 실행은 하지 않았다.

24: `lecture_pdf/homework/지엘3 좌표계 변환 (실습 24).pdf` p.1. 26·27: `lecture_pdf/homework/지엘4 조명 (실습 2627).pdf` p.2~3. 조명 구성: 사용자가 지정한 `지엘4 조명.pdf` p.4~19. 25는 자료가 없어 추정하지 않았다.

## 조명 강의 요소의 반영

`Material`의 Ka/Kd/Ks/shininess, 패스별 카메라 위치, 월드 위치·역전치 법선, 프래그먼트 Phong 계산, 거리 감쇠, 광원 표시 unlit을 연결했다. 강의 p.19의 `float diffuse = ... * lightColor`는 RGB 결과이므로 vec3로 구현한다. 강의의 `Normal=vNormal`을 그대로 복사하지 않고 전체 모델 변환에 대한 역전치 법선을 유지한다.
