시험 현장 구현 순서: 정적 조립에서 관절 제어까지

공통 구현·전체 API 사례응용패턴·그네 통합

기존 시험 순서 문서는 저장소 docs/code-guide/exam.html에 존재한다. 이 문서는 그 순서를 현재 standard의 착석·관절 SRT 조작까지 연결해 독립 폴더 안에서 읽을 수 있도록 정리한 최신판이다. 시험의 실제 제한 시간과 허용 자료는 문제 지시를 따른다.

1. 요구사항을 상태와 함수로 바꾸기

사람이 앉는다, 그네가 흔들린다, 관절을 선택한다, 세 뷰로 본다 같은 동사를 적는다. 각 동사를 좌석 부모 관계, hinge 모션, 선택 인덱스, RenderPass에 연결한다. 출력 조건과 입력 키를 먼저 표로 만든다.

2. 프로젝트·main 골격 준비

standard.sln, x64, Framework.h 포함을 확인한다. main은 Application과 응용 상태를 만들고 init/update/key/render 콜백을 저장한 뒤 run을 한 번 호출한다. 예제 main을 여러 개 프로젝트에 등록하지 않는다.

3. 정적 장면부터 조립

바닥·고정 프레임·좌석·앉은 사람을 먼저 만든다. 부모는 frame→hinge→seat→person.root이며 지지대는 frame의 자식이다. 관절 위치·바라보는 +Z 방향·착석 높이를 애니메이션 없이 확인할 준비를 한다.

4. 각 관절 기준 SRT·피벗 결정

HumanoidPose::seated로 엉덩이·무릎을 굽힌 뒤 createJointAnimation으로 rest를 캡처한다. basis는 부모 공간 위치, localBasis는 모델 피벗이다. 관절 선택 목록은 EntityId 또는 트랙 인덱스를 보관하고 포인터는 보관하지 않는다.

5. 입력 명령 연결

PRESS에서 모드·선택 관절·축을 바꾼다. 방향키·PageUp/Down·+/-는 선택 트랙의 rest만 수정한다. Space는 시간을 정지하고 R은 선택 rest를 복원한다. 애니메이션 함수와 입력이 같은 Scene 변환을 덮어쓰지 않게 한다.

6. 누적 시간과 모션 추가

AnimationClock.advance(dt)로 seconds를 누적하고 poseHierarchy(scene,animation,seconds)를 호출한다. dt를 누적 절대 시간 대신 넘기지 않는다. 선형보간은 편도 시간·재생 방식, 진자는 진폭·주기를 지정한다. Application이 자동 진행하는 MotionSystem을 따로 중복 update하지 않는다.

7. 충돌·추가 패턴은 필요한 경우만 결합

걷기·점프가 요구되면 CharacterBody 상태→stepCharacter→표시 관절 순서로 넣는다. 좌석에 앉은 사람에게 바닥 보행 상태를 그대로 적용하지 않는다. 벽 표시 개방과 실제 충돌 통과를 구분한다.

8. 렌더링·다중 뷰·피킹 연결

기본 renderScene 또는 사용자 renderViews를 택한다. update는 프레임당 한 번, 렌더는 여러 카메라로 반복한다. framebuffer의 크기·viewport 원점·DPI 좌표를 맞춘다.

9. 복원·오류·종료 처리

각 optional/bool 결과를 확인한다. 중복 관절 트랙·0 주기·비균일 rest 배율은 거부한다. 초기화에서 모든 ID·모드·시계를 다시 구성한다. 종료는 requestClose를 사용하고 GPU 해제를 컨텍스트 수명 안에서 처리한다.

10. 사용자가 최종 실행 확인

사용자가 빌드·실행한다. 그네를 멈추고 엉덩이·무릎 착석, 선택 팔꿈치의 자식 전달, hinge의 전체 전달, 지지대 고정, 피벗 이동 후 회전 중심, Space 재개 뒤 편집 유지, 리셋, 세 뷰 일치를 확인한다. 이 작성 작업에서는 실행하지 않았다.

착석·관절 구현 출발 코드

struct SwingExample {
    graphics::AnimationClock clock;
    std::vector<graphics::JointAnimation> animation;
    bool initialize(graphics::Scene& scene) {
        graphics::HumanoidConfig personConfig;
        personConfig.grid.frame=glm::translate(glm::mat4(1),glm::vec3(-2,0,0));
        auto person=graphics::AnimationSystem::addHumanoid(scene,personConfig); if(!person) return false;
        auto pose=graphics::HumanoidPose::seated();
        if(!graphics::AnimationSystem::poseHumanoid(scene,*person,pose)) return false;
        graphics::SwingConfig config;config.pivot={1,3,0};config.pendulum.periodSeconds=3;
        auto swing=graphics::AnimationSystem::addSwingWithRider(scene,config); if(!swing) return false;
        animation=swing->animation;
        graphics::PendulumMotion elbow;elbow.amplitudeDegrees=10;
        graphics::Motion motion;if(!motion.append(graphics::Motion::pendulum(elbow))) return false;
        auto track=graphics::AnimationSystem::createJointAnimation(scene,swing->person.elbows[0],motion);
        if(!track) return false;
        animation.push_back(*track);clock.reset();return true;
    }
    bool update(graphics::Scene& scene,float dt) {
        return clock.advance(dt)&&graphics::AnimationSystem::poseHierarchy(scene,animation,clock.seconds);
    }
};

실제 main 연결

#include "Console.h"

/// 콜백을 등록하고 애플리케이션을 실행한다.
int main() {
    graphics::Application app;
    Console sample(app);

    app.setInitHandler([&](graphics::Application&) {
        return sample.initScene();
    });
    app.setKeyHandler([&](graphics::Application&, int key, int action) {
        sample.onKey(key, action);
    });
    app.setMouseHandler([&](graphics::Application&, const graphics::MouseEvent& event) {
        sample.onMouse(event);
    });
    app.setUpdateHandler([&](graphics::Application&,float dt) {sample.onUpdate(dt);});
    app.setRenderHandler([&](graphics::Application&) {return sample.onRender();});

    graphics::ApplicationConfig config;
    config.title = "standard - Motion, Grid, diagnostics and render passes";
    return app.run(config);
}
