# 3D 실습 세부 요구사항 구현 패턴

공통 framework를 쓰는 실습 13~23의 **세부 동작**을 대상으로 한다. API 목록 대신 상태·시작/재입력·프레임 계산·반영 함수를 연결한다. 번호 없는 이전 3D 예제와 워밍업의 3D 데이터 부분은 [별도 부록](EARLIER_3D.md)에 둔다. 1~12의 2D 구현은 제외한다.

[공통 구현과 standard 복사 순서](COMMON.md) · [이웃 면 교환을 따로 조립하는 완결 예](ADJACENT_FACES.md) · [요구사항과 현재 소스의 차이](SOURCE_NOTES.md)

새 API를 추가하지 않는다. 모든 C++ 블록은 standard 내부 파일 또는 동봉 framework만 참조한다. 원본 경로 링크는 근거이며 코드 의존성이 아니다.

## 읽는 방법

1. 공통 헤더 전문을 같은 standard 폴더에 준비한다.
2. 원하는 실습의 상태·보조부·함수·main 블록을 순서대로 복사한다.
3. 요구사항 표에서 원하는 세부 동작을 찾고 상태를 켜는 함수와 프레임 계산을 함께 읽는다.
4. 여러 실습을 합칠 때 클래스 Console을 중복 정의하지 말고 필요한 상태·시작 함수·갱신 함수만 한 Console로 옮긴다.
5. [차이와 사용자 확인](SOURCE_NOTES.md)을 읽고 직접 빌드·조작한다.

세부 패턴 116개, 실습 문서 11개다. 예: 이웃한 두 면의 선택·공유 모서리 회전·반대 공전 교환은 P15-06~08로 나눴다. 공통 기능은 COMMON.md에 한 번만 둔다.

## 외부 의존성이 없는 구성

코드 블록이 참조하는 사용자 파일은 같은 standard 폴더에 작성할 Console.h/PracticeCommon.h뿐이다. 내용은 모두 이 묶음에 있다.
framework는 standard에 동봉된 폴더다. 다른 실습 파일, 사용자 홈 경로, 외부 모델·텍스처 파일은 코드에서 읽지 않는다.
근거용 원본 링크와 문서 생성 도구는 실행 코드 의존성과 구분한다.

실습별 세부 116개, 공통 묶음 10개, 이전 3D 부록 10개를 구분해 제공한다. 실제 빌드·화면 확인은 사용자 담당이다.
