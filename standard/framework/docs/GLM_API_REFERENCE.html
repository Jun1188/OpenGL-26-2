1. 역할·타입·소유권

GLM은 CPU에서 벡터와 행렬을 계산하는 헤더 기반 C++ 수학 라이브러리이다. GL 컨텍스트 없이 계산할 수 있다. 행렬을 만들었다고 GPU uniform이 자동 변경되지는 않는다.

타입·연산의미주의
vec2 / vec3 / vec4float 성분 2·3·4개vec3(0)은 모든 성분 0. vec4(position, 1)은 점, vec4(direction, 0)은 방향.
dvec2 / dvec3double 성분 벡터Geometry와 경로 계산에서 사용. float 전환 시 정밀도 손실 가능.
ivec3정수 성분 3개GridLayout의 셀 수·인덱스에 사용.
mat3 / mat4float 정사각 행렬mat4(1.0f)는 단위행렬. mat3(mat4)는 좌상단 3×3을 가져와 평행이동을 제외.
m[column][row]열을 먼저 인덱싱열 우선 메모리 배치와 행렬 곱 적용 순서는 서로 다른 개념.
값과 value_ptr행렬·벡터가 데이터를 소유value_ptr는 데이터를 빌린다. 원본 수명이 끝나면 포인터가 무효.

기본 생성한 행렬이 단위행렬이라고 가정하지 않는다. 예제에서는 mat4(1.0f)로 명시한다. GLM 설정 매크로는 처음 GLM 헤더를 포함하기 전에 일관되게 지정해야 한다.

2. 입력 → 변환 → 출력

로컬 정점 → M: 모델 → 월드 → V: 월드 → 뷰 → P: 뷰 → 클립 → GL uniform 전송 → 정점 셰이더
clip = P * V * M * glm::vec4(localPosition, 1.0f);
// 열벡터 기준: 오른쪽 M부터 적용한다.
// P * V * M은 NDC가 아니라 클립 좌표를 만든다.
// 클리핑 뒤 GPU의 원근 나눗셈으로 NDC가 된다.

M = T * R * S;  // 로컬 점에 S → R → T 순서 적용
aroundCenter = T(center) * R * T(-center);
normalMatrix = transpose(inverse(mat3(M)));

현재 Renderer.cpp는 projection * view * model을 만들고 UniformMatrix4fv에 GL_FALSE와 value_ptr를 전달한다. Shaders.h의 정점 셰이더는 uMVP * vec4(vPos, 1.0)을 계산한다. 법선 행렬은 역행렬 계산 전 determinant를 확인한다.

4. MVP와 GPU 전달 예제

Model.h는 glm.hpp와 gtc/matrix_transform.hpp를 포함한다. Renderer.cpp는 gtc/type_ptr.hpp를 추가한다. 아래는 관련 설정이 완료된 뒤의 설명용 조각이다.

const glm::mat4 identity(1.0f);
const auto T = glm::translate(identity, glm::vec3(2, 0, 0));
const auto R = glm::rotate(identity, glm::radians(90.0f), glm::vec3(0, 1, 0));
const auto S = glm::scale(identity, glm::vec3(0.5f));
const auto M = T * R * S;
const auto V = glm::lookAt(glm::vec3(0, 2, 6), glm::vec3(0), glm::vec3(0, 1, 0));
const auto P = glm::perspective(glm::radians(60.0f), 800.0f / 600.0f, 0.1f, 100.0f);
const auto mvp = P * V * M;
// 유효한 current 컨텍스트와 선택된 셰이더 프로그램이 필요하다.
gl.UniformMatrix4fv(mvpLocation, 1, GL_FALSE, glm::value_ptr(mvp));
// 셰이더: gl_Position = uMVP * vec4(vPos, 1.0);

5. 결과가 달라지는 지점

증상확인할 입력·상태관찰할 결과
회전 방향·위치가 예상과 다름M=T*R*S인지, 각도가 라디안인지, 회전 중심 이동 순서가 맞는지로컬 정점 한 개를 오른쪽 행렬부터 계산한다.
원근 화면이 찌그러짐aspect가 정수 나눗셈인지, 높이가 0인지float(width)/height를 사용하며 0 크기에서는 렌더를 건너뛴다.
법선·조명에 NaN 발생0벡터 정규화, 특이행렬 inverse, 비균일 scale법선 길이와 determinant를 검사한다.
CPU 행렬을 바꿨지만 화면이 같음uniform 위치·선택 프로그램·전송 시점현재 프로그램의 uniform에 새 행렬을 전송한다.
깊이 또는 좌표계 해석이 다름GLM_FORCE_LEFT_HANDED / GLM_FORCE_DEPTH_ZERO_TO_ONE 등의 설정기본 GLM은 오른손·NDC 깊이 -1~1 관례를 사용한다. 설정이 있으면 일관되게 해석한다.

회상 질문: M=T*R*S에서 로컬 정점에 먼저 적용되는 변환은 무엇인가? 왜 value_ptr(mvp)만 호출하면 화면은 바뀌지 않는가?
