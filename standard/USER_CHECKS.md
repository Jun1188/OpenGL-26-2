# 사용자 빌드·입력 확인

2026-11-03. 아래는 예상 결과이며 실행 결과가 아니다. 에이전트는 빌드·테스트·검증기·앱 실행을 하지 않았다.

## 시작과 전환

1. standard.sln 또는 지원되는 Visual Studio의 standard.slnx를 연다. x64 Debug/Release, C++17로 사용자가 빌드한다.
2. main의 initialMode를 nullopt, 1, 9, 20, 22로 각각 바꾸어 실행한다. 정수는 해당 모드로 바로 시작하고 전환 키로 다른 모드에 들어가지 않아야 한다.
3. nullopt에서 1→7→2→8→3→9→6을 누른다. 모든 데모에 도달해야 한다. F1~F11은 실습 13~23, 대괄호는 1~22 순환이다.
4. 추가 실습에서 숫자는 고유 기능이다. 예: F1→1은 13번 실습의 육면체 한 면 선택이며 1번 데모 전환이 아니다. Alt+1은 1번 데모로 돌아온다.
5. 고정 9번에서 Home으로 전체 편집값을 복원한다. 0 또는 23을 상수로 지정하면 컴파일 시 범위 오류가 나야 한다.

## 1~9의 선택과 편집

각 모드에서 Space로 정지 → 클릭 선택 → X/Y/Z → 좌우 회전·상하 이동 → 재개를 확인한다. 편집값이 다음 프레임에도 남아야 한다. Tab/Backspace와 R, Home을 확인한다. 회전·이동·배율을 연속 입력하고, 빈 곳 클릭 뒤에는 이전 대상을 편집하지 않아야 한다.

| 모드 | 추가 확인 | 예상 결과 |
|---|---|---|
| 1 | S/G/M/I와 경로 전환 | 타원과 반사 쌍 유지. 한 객체 편집은 다른 객체에 직접 적용되지 않음. |
| 2 | 사각형 경로에서 이동 | 경로 위치와 수동 오프셋이 합성됨. |
| 3 | 다각형 경로·R | 정점 경유 이동. R은 선택 객체 기준값만 복원. |
| 4 | 3D 경로·3뷰 | 보간과 깊이 변화. 세 뷰는 같은 상태를 표시. |
| 5 | 원 경로·피벗 변경 | 피벗 변경 뒤 회전 중심 변화. |
| 6 | 왕복 끝점·Space | 꺾은선 끝에서 돌아오며 정지·재개 시간을 유지. |
| 7 | 초기 방향키·클릭·번호 | 첫 이동 상자가 기본 대상. 번호도 해당 상자를 따라감. 편집 후 경로 추종이 값을 지우지 않음. |

| 8 | 정지 중 F·방 회전·상자 배율 | 바닥 표시 즉시 변경. 방 확대와 상자 피벗 편집은 이유를 출력하고 거부. 재생 후 이탈 자세 유지. |
| 9 | 서 있는 사람의 모든 부위 클릭 | 같은 standing root 선택. 회전·이동 시 사람 전체가 따라감. |
| 9 | 그네 지지대·줄·좌석 클릭 | swing frame 선택. 탑승자는 rider root 선택. |
| 9 | Tab으로 elbow·hinge·torso 선택 | elbow는 아래팔·손, hinge는 줄·좌석·탑승자, torso는 머리·팔에 전달. |

Shift와 Caps Lock을 각각/동시에 켜서 대소문자 방향을 확인한다. 방향키나 카메라 이동을 누른 채 다른 창으로 전환하고 돌아와도 놓친 release 때문에 계속 이동하지 않아야 한다. 창 리사이즈·DPI·최소화 복귀 후 3뷰의 각 영역에서 피킹을 확인한다. 종료는 모든 모드에서 Esc를 사용한다.

## 한계와 독립 배포

물리 충돌은 교육용 AABB 모델이다. 정확한 회전 메시·강체 토크·마찰을 보장하지 않는다. 선·투명 픽셀·사용자 셰이더 변형은 삼각형 피킹과 다를 수 있다.

standard 전체를 다른 경로로 복사해 상위 공용 framework와 다른 실습 폴더 없이 빌드·실행한다. DLL·라이선스가 동봉된 폴더 구조를 유지한다. 실제 화면·입력·다른 PC 동작의 완료 판단은 사용자가 수행한다.
