# 실습 18

openGL_assign_18.slnx를 Visual Studio에서 열고 Debug/Release x64로 빌드한다. C++17·v145를 사용한다. 빌드와 실행 테스트는 사용자가 수행한다.

main.cpp는 콜백을 등록하고 Console이 해당 실습의 입력·상태·장면을 관리한다. framework 폴더가 모든 외부 라이브러리를 포함한다. 프로젝트 폴더 전체를 복사하여 단독 제출할 수 있다. DLL은 실행 폴더의 framework/dependencies로 배치된다.

상세 키와 예상 결과는 저장소 docs/practice-14-19/README.md와 USER_CHECKS.md에 있다. 프레임워크 공통 응용 패턴은 framework/docs/APPLICATION_PATTERNS.md에 있다. 단독 배포 시 Console.cpp의 시작 안내와 onKey를 함께 참고한다.

### 18

중심 구 반지름 0.55. 행성 궤도 반지름 2.0/2.8/3.6, 공전 속도 20/30/40°/초다. 달의 초기 공전 궤도 3개는 모두 월드 XZ 평면에 놓인다. 현재 카메라에서는 가로로 누운 타원으로 보이며, 달은 70/100/130°/초로 공전한다. 세 행성 궤도는 XZ와 Z축 기준 ±45°다.

p/P는 직교/원근, m/M은 솔리드/와이어다. WASD는 XY, +/-와 키패드 +/-는 Z 양/음 이동이다. 1은 모든 궤도 반지름을 1배/1.3배로 1초 동안 변경한다. 2는 중심 구의 ±18% 크기 변화·색상 변화 정지/재개다. 3은 달의 궤도와 달을 행성 중심을 지나는 월드 Z 방향 축 주위로 25°/초 회전/정지하고, 달 자체의 로컬 Y축 자전도 90°/초로 재개/정지한다. 각 달에 부착한 노란 방향선으로 솔리드 모드에서도 자전을 구분한다. 공전은 계속된다. Q/Esc는 종료다.

궤도 선과 천체는 같은 평면·반지름을 사용한다. 중심 구와 행성의 시각적 크기가 자식 궤도의 반지름을 바꾸지 않는다.


사용자 확인: 초기 달 궤도 3개의 수평 배치, 3번 키로 궤도 회전·자전 재개/정지와 노란 방향선의 회전(공전은 계속됨), 빌드, 조작 키, 상대경로 배포, 창 크기·최소화·포커스 이탈·종료를 직접 확인한다.
