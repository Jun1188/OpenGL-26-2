# 실습 19

openGL_assign_19.slnx를 Visual Studio에서 열고 Debug/Release x64로 빌드한다. C++17·v145를 사용한다. 빌드와 실행 테스트는 사용자가 수행한다.

main.cpp는 콜백을 등록하고 Console이 해당 실습의 입력·상태·장면을 관리한다. framework 폴더가 모든 외부 라이브러리를 포함한다. 프로젝트 폴더 전체를 복사하여 단독 제출할 수 있다. DLL은 실행 폴더의 framework/dependencies로 배치된다.

상세 키와 예상 결과는 저장소 docs/practice-14-19/README.md와 USER_CHECKS.md에 있다. 프레임워크 공통 응용 패턴은 framework/docs/APPLICATION_PATTERNS.md에 있다. 단독 배포 시 Console.cpp의 시작 안내와 onKey를 함께 참고한다.

### 19

12×12 바닥 위에서 방향키로 XZ 이동한다. 모든 부품의 회전 범위를 포함한 반경 2.5를 남겨 루트 위치를 X/Z ±3.5로 제한한다. 포신과 깃대를 포함한 모든 부품을 직육면체로 구성한다.

d는 하부 높이 ±25% 진동, t는 중앙 몸체 Y 자전, l은 상부 두 개의 반원 경로 교환이다. g는 포신의 반대 Y 회전, p는 깃대의 반대 X 회전(±60°)이다. 각각 같은 키로 정지/재개한다. l은 완료 후 재입력하면 복귀한다.

z/Z·x/X는 카메라 Z/X 양·음 이동이다. 누르는 동안 position과 target을 함께 이동한다. y/Y는 실제 카메라 Y축 기준 시계/반시계 자전, r/R은 원점의 월드 Y축 기준 공전이다. 같은 방향 재입력은 정지한다. o는 바닥과 부품 색상을 순환하고 c는 전체 초기화한다. Q/Esc는 종료다.


사용자 확인: 빌드, 조작 키, 상대경로 배포, 창 크기·최소화·포커스 이탈·종료를 직접 확인한다.
