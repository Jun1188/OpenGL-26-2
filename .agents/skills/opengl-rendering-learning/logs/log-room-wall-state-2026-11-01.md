# 벽 개방 상태와 시점별 컬링 구분

- 날짜: 2026-11-01
- 대상: 실습23 Console::onKey/onUpdate, PatternSystem::cameraFacingWall/openRoomWall
- 승인: 사용자 전체 추가 범위 승인. 빌드·테스트·실행·ZIP 제외.

## 증상과 근거

사용자가 O 이후 카메라를 반대로 옮겼을 때 한 벽이 사라진 상태를 보고했다. 이전 소스는 O마다 카메라 방향으로 새 벽을 선택하고 벽별 open 상태를 유지했다. 따라서 이미 연 벽은 다른 벽을 선택해도 열린 채 남을 수 있다. 이는 소스상의 가능한 원인이며, 보고된 화면의 단일 원인으로 실행 확인한 것은 아니다.

## 수정

시선 target-position과 바깥 법선의 양의 내적이 최대인 맞은편 벽을 선택한다. 첫 O에서 activeWall을 저장하고 이후 O는 같은 벽의 개방 목표만 반전한다. 완전 복원 후 선택을 해제한다. 초기화 때 네 벽을 모두 복원하고 윤곽선을 추가한다. Front cull은 winding에 따른 시점별 표시, O는 진행률에 따른 축소/가시성 상태로 구분한다.

## 학습 문서

공통 시험 행동 그래프와 API 호출 안내를 먼저 두고 실습을 예시로 연결했다. 공개 API는 선언마다 한글 기능 주석과 API_KO.md를 제공한다. 표면 명암·깊이 가림·컬링과 투영 그림자를 구분했다. 현재 cast shadow는 없다.

## 미확인 사항

사용자에게 초기 네 방향 공전, O→공전→O 복원, 빠른 재입력, I 초기화와 한글 표시 확인을 맡긴다. 빌드/실행/브라우저 확인을 수행하지 않았다. 사용자 이해 확인도 완료로 기록하지 않는다.
