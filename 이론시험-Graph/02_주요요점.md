# 사용법과 답안 틀
이 요약은 전체 정리본을 한 번 읽은 뒤 회상하는 용도다. 실제 출제 비율·중요도는 확인되지 않았다. 아래 우선순위는 사용자가 알려 준 서술·계산 유형을 고려한 학습 순서다.
서술형은 '정의 → 작동 원리 → 비교 기준 → 조건·한계 또는 예'로 쓴다. 계산형은 '좌표·단위 약속 → 공식 → 대입·중간 단계 → 결과와 조건'으로 쓴다. 용어만 나열하지 않는다.
우선 연습: 벡터·래스터 비교, DDA·Bresenham 추적, 채우기와 내부 판정, 임의점 변환·반사축 행렬, 윈도우 매핑·클리핑, 조명 합산과 셰이딩 보간. 역사·활용·장치도 범위에 포함하며 출제되지 않는다고 제외하지 않는다.

# 1장. 정의·표현·시스템
- 그래픽스는 영상을 생성·표현,영상처리는 기존 영상의 변환·개선·분석에 초점이 있다. [p.2]
- 발전: 대화식 그래픽스 → 3D·셰이딩 → PC·GUI·CAD → 3D API·GPU → PBR·HDR·VR/AR·Ray Tracing·AI. 강의 연표는 전체 정리1.2를 본다. [p.2~5]
- 벡터는 기하·수식,래스터는 픽셀 배열이다. 벡터는 확대 시 재계산,래스터는 해상도에 의존한다. 도면·로고와 사진·질감을 비교한다. 벡터 파일이 항상 작다는 단정은 피한다. [p.7~8]
- 3D 흐름: 모델링은 형상,뷰잉은 카메라,투영은3D→2D,렌더링은 색·밝기의 최종 생성이다. 최종 화면은2D 픽셀이다. [p.9~11]
- 와이어프레임·다각형 표면·솔리드는 선·면·부피의 표현 차이다. 평행·원근 투영은 투영선과 거리감의 차이다. [p.10~11]
- 랜덤 스캔은 선 명령 재생,래스터 스캔은 프레임 버퍼의 픽셀 재생이다. 이중 버퍼는 표시와 다음 그림 작성을 분리한다. [p.16~17]
- GPU는 다수의 유사 계산을 병렬 처리하고 셰이더는 GPU의 처리 방법을 정한다. 응용프로그램 → 라이브러리 → 하드웨어를 구분한다. [p.12~19]

# 2장. 격자·판별·채움
- 점의 기하 위치와 출력 픽셀을 구분한다. 선은 절대좌표의 두 끝점 또는 시작점+상대 증분으로 정한다. 수직선은 기울기 분모0을 피한다. [p.3~4]
- DDA: 주축을 고르고 실수 좌표를 누적한 뒤 출력만 반올림한다. steps=max(|dx|,|dy|). 음의 진행 방향은 증분 부호로 처리한다. [p.5~7,일반화 유도]
- Bresenham 선: 기본 조건0≤m≤1,dx>0. p초기=2dy-dx. p<0이면E,p≥0이면NE다. p=0의 동점 규칙을 바꾸지 않는다. [p.8~13]
- Bresenham 원: 중심 상대좌표(0,r),p초기=3-2r. x증가,y유지 또는1감소. 갱신 전 x,y로 p를 계산한다. 한 팔분면 후8방향 대칭·중복 제거. [p.14~17]
- 4방향은 상하좌우,8방향은 대각선 포함이다.8방향 경계에4방향 내부를 사용하여 대각선 누출을 피한다. [p.18~19]
- Flood는 기존 영역색,Boundary는 경계색이 기준이다. 전자는 같은 색의 연결 영역,후자는 닫힌 경계 내부를 탐색한다. [p.20,23~25]
- 홀짝은 교차 수의 홀수 여부,접기회수는 방향 합≠0이다. 같은 방향 두 번은 결과가 다를 수 있다. [p.21~22]
- EL은 전체 에지의 ymin 정렬,AEL은 현재 행의 활성 에지. 교차 x정렬→두 개씩 짝→구간 채움. 다음 행은 x+=1/m. 수평 에지와 공통 꼭짓점은 별도 규칙. [p.26~28]
- 앨리어싱은 부족한 샘플링에 따른 계단·흔들림. SSAA는 전체 고밀도,MSAA는 여러 피복 샘플과 셰이딩 공유,FXAA·MLAA는 후처리다. [p.29~34]
회상: 'DDA의 출력 y를 다음 단계 누적 y로 쓰면 왜 안 되는가?'

# 3장. 변환은 기준점과 순서
- 열벡터 P=[x,y,1]^T. 동차3×3은 이동·회전·신축의 표현과 합성을 통일한다. 방향은 보충적으로 w=0이다. [p.3~4,10]
- A를 먼저,B를 나중에 적용하면 B*A*P. 결합법칙은 성립,교환법칙은 일반적으로 불성립. [p.11]
- 임의점C 변환: T(C)*변환*T(-C). 기준점C를 대입해 고정되는지 본다. 회전 후 원점 기준 스케일인지 같은C 기준 스케일인지 구분한다. [p.6,8~12]
- 양의 회전은 반시계.90도는(-y,x),-90도는(y,-x). 기본점(1,0)으로 부호를 판단한다. [p.7]
- x축 반사는 y부호,y축 반사는 x부호,원점 반사는 둘 다 바꿈. y=x는 교환,y=-x는 교환 후 두 부호 반전이다. [p.13~14]
- y=m*x+b 반사는 직선을 원점·x축에 맞춘 후 x축 반사하고 역순 복원한다. [p.15]
- x밀림:x'=x+h*y,y'=y. y밀림:x'=x,y'=y+h*x. 고정선에서 멀수록 변위가 크다. [p.16]
- 강체는 길이·각도,유사는 균일 길이배율과 모양,선형은 벡터 연산과 원점,비퇴화 어파인은 직선·평행성과 한 직선 위의 비를 보존한다. [p.17~18]
- 이동은2D 선형이 아니다. 비균일 신축은 일반적으로 유사변환이 아니다. 선형·유사의 포함관계를 무조건 한 줄로 세우지 않는다. [p.17~18,조건 보완]
회상: 'C 중심 회전에서 맨 오른쪽 이동의 부호가 왜 -C인가?'

# 4장. 무엇을 볼지와 어디에 놓을지
- 윈도우는 선택한 월드 영역,뷰포트는 표시할 출력 영역. 윈도우 축소는 확대,위치 이동은패닝이다. [p.3~4]
- 매핑: 윈도우 최소점 빼기→축별 배율→뷰포트 최소점 더하기. sx≠sy이면 왜곡될 수 있다. [p.5~6]
- 점은 네 경계 부등식을 모두 만족하면 내부. 선은 양끝이 외부여도 일부가 보일 수 있다. [p.8~9]
- Cohen-Sutherland: TBRL순서,left=1,right=2,bottom=4,top=8. OR=0 채택,AND≠0 기각,그 외 교차 후 재판정. AND=0을 채택으로 오해하지 않는다. [p.10~12]
- Liang-Barsky:p*u≤q,p<0은진입하한,p>0은이탈상한. p=0,q<0은바깥 평행선이므로 기각. p=0,q≥0은제약없음. [p.13~17]
- uin=max(0,진입후보),uout=min(1,이탈후보). uin>uout 기각,같으면한 점 접촉. [p.17,경계 포함 보완]
- S-H: 안→안E,안→밖I,밖→안I와E,밖→밖없음. 한 경계 출력목록을 다음 경계에 전달한다. 닫힘 에지도 포함한다. [p.21~23]
- W-A: 진입·이탈 교점에서 다각형 경계와 클립 경계를 전환하여 여러 분리된 결과 윤곽을 추적한다. [p.24,보충 출처]
회상: '양끝 영역코드가0001,1000이면 왜 추가 계산이 필요한가?'

# 5장. 한 점의 조명과 면의 보간
- 주변광은 균일 기본 밝기,산란광은 법선·광원 방향,거울광은 관찰자·반사 방향에도 의존한다. [p.3~7]
- N,L,V,R는 같은 좌표계의 단위벡터다. L은 표면→광원,V는 표면→관찰자. 정규화 후 내적을cos로 쓴다. [p.8~12]
- 강의 계산식은 Ip/d다. p.4의 물리적1/d² 설명과 구분하고 문제에 주어진 감쇠를 우선한다. 주변광까지 나누지 않는다. [p.4,9~12]
- Lambert=주변+산란,Phong 조명=주변+산란+거울이다. 음의 내적은0으로 자른다. [p.7~12]
- Ks는 거울광 세기,n은 집중도다. n증가→하이라이트가 좁아짐. V·R=1의 최대값은 n만으로 증가하지 않는다. [p.11]
- Flat은 면 상수,Gouraud는 정점 밝기 보간,Phong 셰이딩은 법선 보간·재정규화 후프래그먼트 조명이다. [p.13~16]
- Phong 조명 모델과 Phong 셰이딩은 다르다. Gouraud의 정점에서도 Phong 반사식을 쓸 수 있다. [p.11~16]
- 보간 가중치의 합은1이다. 보간 법선의 길이가1인지 확인한다. Gouraud는 정점 사이의 좁은 하이라이트를 놓칠 수 있다. [p.14~15]
- 광선추적은 직접광+반사+굴절. 미교차·광원 도달·횟수 제한·기여 임계값을 종료 조건으로 사용한다. [p.17~18]
