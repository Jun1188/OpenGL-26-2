# 실습 27: 사용자 확인

이 폴더 전체를 저장소 밖의 별도 경로로 **복사**한 뒤 `.sln`의 Debug/Release x64를 사용한다. 원본을 이동·삭제할 필요는 없다. 폴더 내부 framework에 소스·헤더·GLM/GLFW·런타임 DLL·셰이더·라이선스가 포함돼 있다. 상위/형제 framework를 참조하지 않는다. Visual Studio C++ 도구·Windows SDK·OpenGL 3.3 지원 드라이버는 시스템 요구다.

빌드·테스트·앱 실행은 에이전트가 수행하지 않았다. 아래 확인은 사용자가 수행한다.

1. **시작**: 구 3개: 중앙 1개와 다른 위치 2개. 예상: 중앙 (0,0,0), 왼쪽 (-3,0,0), 오른쪽 (3,0,0); 구별 반지름·재질색.
2. **시작/apply**: 화면 앞쪽 광원과 작은 표시 객체. 예상: 초기 (0,2,5), .2 크기 비조명 표시.
3. **c**: 광원색 3종 전환. 예상: 백색/적색 계열/청색 계열을 순환; 표면 재질색과 별도로 저장.
4. **r/R**: 중앙 구의 Y축 기준 양/음 공전. 예상: 중심 (0,0,0)의 Y축 둘레, 일정 높이 2; 재입력으로 정지.
5. **q**: 종료. 예상: Application::requestClose.

공통 관찰: 셰이더 오류·GL 오류가 없어야 한다. 프레임률이 달라도 시간당 속도는 같아야 한다. 리셋과 방향 전환을 반복해도 객체가 늘거나 잘못된 부모에 남지 않아야 한다.
