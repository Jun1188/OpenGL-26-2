# 프레임워크 정리와 실습 14~19

## 실행과 배포

- 기존 13~15 솔루션 이름은 유지한다. 신규 실행 파일은 각 openGL_3dAssign_16~19의 openGL_assign_번호.slnx에서 만든다.
- 새 프로젝트는 Visual Studio v145, C++17, Debug/Release x64다. 13~15도 C++17을 사용한다. 이전 실습의 기존 언어 표준은 유지했다.
- 각 13~19 폴더는 프레임워크를 포함한다. 프로젝트 폴더 전체를 복사하면 단독으로 사용할 수 있다.
- 저장소 루트 framework가 원본이다. 승인된 변경을 배포할 때 tools/Sync-Framework.ps1을 직접 실행한다. 기존 복사본의 개별 수정은 덮어쓰므로 먼저 보존한다. 빌드는 소스 복사본을 동기화하지 않는다.
- 실행 DLL은 x64/구성/framework/dependencies에 배치된다. 기본 셰이더는 내장되어 있다. 자산은 실행 폴더의 data/models/textures에서 읽는다. 작업 디렉터리나 개발자 소스 경로 탐색을 사용하지 않는다.
- 라이브러리는 framework/dependencies 안에 있다. 기존 1~12는 OpenGL.props -> framework/LegacyOpenGL.props를 사용한다. Windows SDK·그래픽 드라이버·VC 런타임은 시스템 환경이다.

## 좌표와 회전

입력 정점 -> 피벗 이동 -> 크기 -> 회전행렬 -> 부모 좌표의 위치 -> 조상 행렬 -> view -> projection -> 화면이다.

Transform3D.rotation은 항등 mat3이다. 초기 표시 기울기를 회전값에 섞지 않는다. 14~17은 카메라 시점으로 30° 표시를 처리한다. 로컬 자전은 오른쪽 곱, 원점 공전은 부모 그룹 회전이다. 프레임워크 자체의 쿼터니언 처리와 별도 초기 기저 보정은 제거했다. 일반 rotation 행렬은 유한·정규직교·오른손 회전이어야 한다. 피벗의 크기 0 변환은 면 축소에 사용할 수 있다.

13은 기존 화면 배치를 보존하여 모델의 초기 회전행렬을 명시한다. 14~19의 객체는 항등 회전으로 시작한다. 18의 궤도 평면, 19 부품 피벗은 표시 보정이 아닌 요구된 장면 변환이다.

## 실습별 동작

### 14·15

객체 초기 회전은 항등이며 카메라가 X/Y 30° 표시 시점을 만든다. 기존 도형 전환·이동·면 모션과 키는 유지한다. 14의 x/X·y/Y는 현재 로컬 축 회전이다. 15의 Y 자전은 일반 Y 회전행렬이다. 초기화는 보정된 쿼터니언을 복구하지 않는다.

### 16

15의 육면체 키와 H/P/Y/R/Q를 유지한다. 6~9를 누르면 사각뿔을 선택한다. 6~9는 같은 네 옆면을 제어하므로 서로 다른 사각뿔 모드를 고르면 닫힌 자세에서 새 모드를 시작한다. 바닥은 고정한다.

- 6: 모든 옆면을 아래 모서리에서 바깥쪽으로 회전하여 아래 공통 꼭짓점에서 만나게 한다. 같은 키는 열기/닫기 방향을 바꾼다.
- 7: 앞/오른쪽/뒤/왼쪽 순서로 한 면씩 1초 열고 1초 닫는다. 같은 키는 정지/재개다.
- 8: 앞/뒤 면이 위 꼭짓점의 Y축을 중심으로 반대 방향 180° 이동하여 자리를 바꾼다. 도중에는 정지/재개, 끝난 뒤에는 복귀한다.
- 9: 위 꼭짓점을 고정하고 네 옆면을 바깥쪽으로 45° 연다. 같은 키는 방향을 바꾼다.

높이 0.8·반폭 0.4다. 6의 실제 힌지 회전은 바깥 방향 233.130°, 7의 바깥 평면 펼침은 116.565°다. 문서의 180°·90°를 목표 자세로 해석했다. 꼭짓점을 직접 밀거나 면의 크기를 바꾸지 않는다. 6은 아래 공통 꼭짓점에 도달하는 바깥쪽 경로를 사용한다. 충돌 검사는 실습 요구 범위가 아니다.

### 17

1 왼쪽/2 오른쪽/3 모두를 선택한다. 초기 좌측 원뿔·우측 육면체, 위치 X ±1, 크기 배율 0.65다.

- x/X·y/Y: 로컬 양/음 자전, r/R: 원점 Y축 양/음 공전. 같은 방향 재입력은 정지한다.
- a/A: 제자리 크기 ×1.1 또는 ÷1.1. b/B: 위치와 크기를 함께 변경한다. 배율은 0.15~3으로 제한한다.
- d/D: 왼쪽/오른쪽, e/E: 위/아래. 누르는 동안 이동하고 포커스 이탈 시 해제한다.
- t: 2초 직선 교환. u: 2초 동안 한 객체는 위로, 다른 객체는 아래로 우회하여 교환한다.
- v: 두 객체가 반대 위상의 ±35% 크기 변화와 자전·공전을 한다. t/u/v 중 하나만 실행한다. 현재 위치에서 모드를 전환하며 같은 키는 정지/재개다.
- c: 두 객체의 원뿔 -> 구 -> 육면체 순환. 위치·회전·크기를 보존한다. s는 전체 초기화, q/Esc는 종료다.

개별 자전·공전과 교환은 독립 상태다. 교환이 잠시 멈춰도 개별 자전·공전을 별도로 켜 두었다면 그 동작은 계속된다. 이동·크기 명령과 활성 위치 애니메이션이 같은 값을 제어하면 위치 애니메이션이 그 프레임의 위치를 결정한다.

### 18

중심 구 반지름 0.55. 행성 궤도 반지름 2.0/2.8/3.6, 공전 속도 20/30/40°/초다. 달은 화면과 평행한 초기 궤도에서 70/100/130°/초로 공전한다. 세 행성 궤도는 XZ와 Z축 기준 ±45°다.

p/P는 직교/원근, m/M은 솔리드/와이어다. WASD는 XY, +/-와 키패드 +/-는 Z 양/음 이동이다. 1은 모든 궤도 반지름을 1배/1.3배로 1초 동안 변경한다. 2는 중심 구의 ±18% 크기 변화·색상 변화 정지/재개다. 3은 달의 궤도와 달을 행성의 Z축 주위로 25°/초 회전/정지한다. Q/Esc는 종료다.

궤도 선과 천체는 같은 평면·반지름을 사용한다. 중심 구와 행성의 시각적 크기가 자식 궤도의 반지름을 바꾸지 않는다.

### 19

12×12 바닥 위에서 방향키로 XZ 이동한다. 모든 부품의 회전 범위를 포함한 반경 2.5를 남겨 루트 위치를 X/Z ±3.5로 제한한다. 포신과 깃대를 포함한 모든 부품을 직육면체로 구성한다.

d는 하부 높이 ±25% 진동, t는 중앙 몸체 Y 자전, l은 상부 두 개의 반원 경로 교환이다. g는 포신의 반대 Y 회전, p는 깃대의 반대 X 회전(±60°)이다. 각각 같은 키로 정지/재개한다. l은 완료 후 재입력하면 복귀한다.

z/Z·x/X는 카메라 Z/X 양·음 이동이다. 누르는 동안 position과 target을 함께 이동한다. y/Y는 실제 카메라 Y축 기준 시계/반시계 자전, r/R은 원점의 월드 Y축 기준 공전이다. 같은 방향 재입력은 정지한다. o는 바닥과 부품 색상을 순환하고 c는 전체 초기화한다. Q/Esc는 종료다.

## 정적 검토에서 반영한 보정

전체 분석에서 2D 실습 resource.h 네 파일의 CP949를 확인하여 주석·정의를 보존하고 UTF-8 BOM으로 변환했다. 개인 user.props가 외부 SDK를 주입하지 않도록 OpenGL 프로젝트의 사용자 속성 import를 제거했다. 카메라 자전은 실제 카메라 Y축을 사용하며, 와이어는 물체 색과 전체 면의 깊이 전처리를 사용한다. 실습 17의 c는 선택 상태와 관계없이 두 도형을 모두 바꾼다.
