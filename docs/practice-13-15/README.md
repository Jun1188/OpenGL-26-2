# 실습 13·14·15 구현과 사용자 확인

## 파일과 실행 구성

- 실습 13: ../../openGL_3dAssign_13/openGL_assign_13.slnx
- 실습 14: ../../openGL_3dAssign_14/openGL_assign_14.slnx
- 실습 15: ../../openGL_3dAssign_15/openGL_assign_15.slnx
- 공용 소스 사본: ../../framework/
- 전체 코드 변경 대조: CHANGES.md
- 구조 그래프: ../../graphify-out/graph.html
- 콜백과 CPU→GPU 흐름: ../../graphify-out/EXECUTION_FLOW.md

각 실습 폴더에는 framework와 의존성이 있다. 프로젝트 파일의 예전 이름
openGL_sample2.vcxproj는 유지하고 ProjectName, 새 프로젝트 GUID, 솔루션 이름으로 구분한다.
Win32 구성은 배포 라이브러리와 맞지 않는다. Debug|x64를 선택한다.
저장소 루트와 각 실습의 framework는 독립 사본이다. 자동 동기화하지 않는다.
기존 사용자 변경과 FreeGLUT packages 폴더는 작업과 커밋에 포함하지 않는다.

## 사용자에게 맡기는 빌드·테스트

빌드나 실행 테스트는 에이전트가 수행하지 않았다. 아래 확인은 사용자가 직접 수행한다.

1. Visual Studio에서 각 솔루션을 열고 Debug|x64로 빌드한 뒤 실행한다.
   빌드 후 실행 파일 옆에 glew32.dll, glfw3.dll, shaders 폴더가 있어야 한다.
2. 실습 13: 1~6은 각각 육면체 한 면, 7/8/9/0은 사각뿔 한 옆면을 표시해야 한다.
   c는 중복 없는 두 면, t는 바닥과 한 옆면으로 이전 선택을 교체해야 한다.
3. 실습 14: c/p 전환 전후 위치와 회전·렌더 설정을 유지해야 한다.
   w와 W, x와 X, y와 Y를 Shift 및 Caps Lock 조합으로 확인한다.
   와이어에서 사각형의 삼각분할 대각선이 없어야 한다.
   방향키 이동 중에도 좌표축은 고정되어야 한다. s는 현재 도형의 이동·회전을 초기화한다.
4. 실습 15: t/s/1/2/4/5 재입력은 정지·재개, f/b 재입력은 방향 반전이어야 한다.
   f의 윗모서리와 s의 왼쪽·오른쪽 면 중점은 각 모션 단독 실행에서 고정되어야 한다. b는 중점에서 사라지고 복원되어야 한다.
   1은 공유 수직 모서리로 계속 회전하고, 2는 인접 두 면의 자리 교체와 복귀를 반복해야 한다.
   모든 면 동작과 y 자전을 중첩할 수 있다. 한 모션의 정지·완료는 다른 모션을 멈추지 않는다.
   p는 면 동작만 초기화하고, r은 육면체와 초기 상태 전체를 복원한다.
5. h로 깊이 테스트를 전환하여 가려지는 면이 달라지는지 확인한다.
   창 크기 변경·최소화·복원, 실습 14에서 방향키를 누른 채 포커스 이탈,
   q/Esc 종료를 확인한다. 실행 파일을 다른 작업 폴더에서 시작해 셰이더 탐색도 확인한다.

## 구현 기본값

객체 크기 0.8, 초기 X/Y 회전 30도, 직교 투영의 짧은 화면 축 범위 ±1.
축 끝점 ±1. 이동 0.5단위/초, 회전 45도/초, 열기·닫기와 축소·복원 1초.
육면체 면: 앞·뒤·왼쪽·오른쪽·위·아래.
사각뿔 면: 앞·오른쪽·뒤·왼쪽·바닥.
실습 15의 s는 왼쪽·오른쪽 두 면의 중점 X축, 5는 위·아래·앞·뒤 면이다.

## 정적 확인과 실행 확인의 차이

파일 참조, SHA-256 일치, 인코딩, 소스 계약과 Git diff는 정적으로 확인한다.
실제 컴파일, 셰이더 컴파일, 화면 표시, 입력 동작, 종료 시 자원 해제는 사용자 확인 필요다.

모션 중첩 순서는 T/F/S/B/1/2/4/5이며 마지막에 객체 변환을 적용한다. 1은 8초 주기, 2는 교체 2초·복귀 2초 주기다. 선택 쌍은 정지·재개 중 유지하며 P/R 초기화 후 다시 선택한다.
