목차 · 시험 행동 그래프

중간고사 코딩테스트 · 요구사항에서 행동으로

실습을 그대로 외우는 자료가 아니라 혼합·변형 요구를 구현 행동으로 바꾸는 지도다. 실제 시험 시간·표준 코드 사용 허용 여부는 제공되지 않았다. 아래 순서는 권장 학습 전략이며 시험 규정의 사실이 아니다. standard를 사용할 수 없다면 같은 책임을 직접 구현하는 순서로 해석한다.

행동 그래프

요구 계약→최소 창→정적 Scene→입력/상태→필요 기능 분기→최종 변환→기본 렌더→추가 뷰/표현→대조
아래 항목을 고르면 우선 구현 순서가 좁혀진다. JavaScript 없이도 모든 행동 카드와 표를 읽을 수 있다.

전체 행동 카드를 확인한다.

0. 문제를 계약으로 분해

필수 출력·키·객체·좌표계·시간·충돌·카메라를 표로 적는다. 요구되지 않은 기능은 뒤로 둔다.

1. 최소 창·종료 경로

허용된 standard에서 출발한다. main→init/update/input/render 등록과 종료를 남기고 데모 상태를 줄인다.

2. 정적 장면

바닥→대표 객체1개→좌표축/정면표식. 초기 카메라와 투영을 결정한다.

3. 계층·피벗

부품인가? 루트→관절 그룹→표시 메시. 연결 위치와 메시 배율을 분리한다.

4. 입력과 상태

press 토글/repeat/누르는 동안 이동을 구분한다. reset이 되돌릴 상태를 함께 정의한다.

5. 단일 시간·경로

시간 주인은 한곳. path distance·offset·공전/자전·순차 모션을 구분한다.

6. 충돌·접지

계산용 후보 위치→반크기 경계→충돌 해결→최종 Scene 변환. 상승/하강/착지를 구분한다.

7. 카메라·뷰 분할

기본1뷰를 만든 뒤 view/pass를 추가. 업데이트1회, 카메라별 렌더 N회. viewport별 aspect/clear.

8. 표현과 명암

색·선·방향광·컬링을 요구대로 적용. 그림자가 진짜 필수인지 표면 명암인지 구분한다.

9. 요구사항 대조

필수 키·초기 상태·정지/재개·reset·경계·최소화를 사용자가 확인. 미완료 기능을 숨기지 않는다.

혼합·변형 문제 세 가지를 읽는 방법

A. 점프하는 로봇을 세 카메라로 보여 주기

23식 정적 로봇/장애물→발·충돌·접지→관절 보행→22식 pass 추가

충돌 상태를 카메라마다 따로 만들지 않는다. 세 화면이 동일한 feet와 관절을 읽게 한다.

B. 기울어지는 방 안의 컨베이어

방 로컬 축→20식 거리 경로→방→월드 표시→개방 시 월드 낙하

경로 위치를 방 로컬로 계산했으면 방 회전은 한 번만 합성한다. 이탈 후에도 방 자식으로 남겨 다시 회전시키지 않는다.

C. 카메라 쪽 문을 열고 무작위 객체 생성

카메라/방 법선→선택 벽 ID→개방 진행률→기존 객체와 비겹침 배치

문 선택·면 컬링·충돌 통과 판정은 세 책임이다. 문제에서 통과를 요구하면 표시만 축소하지 말고 해당 충돌 경계도 바꾼다. 현재23은 경계에서 돌아서는 규칙을 유지한다.

코딩 시작용 책임 골격

State: 입력/모드/시간/논리 위치/충돌체/Scene ID
initScene(): 정적 배치 + 관절 + 초기 camera + 초기 state
onKey(): 입력을 state 명령으로 변환 (계산/렌더를 모두 넣지 않음)
onUpdate(dt):
    입력 의도 → 후보 위치/각도
    경로·충돌·접지 해결
    논리 상태 확정
    Scene에 최종 transform 반영
onRender(): 같은 Scene을 필요한 카메라별로 출력
reset(): state와 ID를 함께 복구

끝나기 전에 확인할 질문

요구의 각 동사를 하나의 상태와 함수로 연결했는가? reset이 모든 상태를 되돌리는가? 같은 좌표를 두 시스템이 덮어쓰는가? 광원과 카메라를 혼동했는가? 아직 구현하지 않은 것을 구현했다고 적지는 않았는가? 시험 시간 배분은 실제 제한 시간을 확인한 뒤 정한다.

소스와 graphify AST/정의 앵커를 대조한 학습 자료다. 실행 순서 설명은 실제 콜백 코드로 보완했다. 그래프의 동명 심볼·함수 포인터 간선은 확정 호출로 해석하지 않는다. 빌드·실행·테스트·검증기·브라우저 시각 확인은 수행하지 않았고 사용자에게 맡긴다. ZIP을 만들지 않았다.
