독립 graphify 그래프 · 1289노드/1963간선

시험장에서 무엇부터 할까?

중간고사 코딩테스트 행동 그래프 — 요구사항 카드, 우선 행동 분기, 혼합·변형 예시, 책임 골격과 증상별 복귀 지점. 실습별 복사 순서가 아닌 일반 구현 전략이다.

그림자·명암

각 notes 페이지에서 방향광 명암/깊이 가림/Front culling/투영 그림자를 구분한다. 현재 셰이더에는 cast shadow 기법이 없다.

근거와 한계

code-only graphify AST + source-definition anchors, 외부 LLM/API 호출 0. 기존 query CLI는 UTF-8 BOM 입력을 읽지 못해 직접 UTF-8-SIG JSON 로딩으로 근거를 읽었다. 새 6개 scope 그래프를 각각 생성했다. 생성 그래프의 dangling endpoint 및 동일 노드쌍 간선 축약은 GRAPH_HEALTH.md에 남아 있으므로 완전한 동적 호출 그래프로 해석하지 않는다.
