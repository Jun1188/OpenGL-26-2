# 두 물체 튜토리얼 작성 결과

- 작성물: standard/docs/WORKSPACE_TUTORIAL.html 및 .md, 레시피3개, 출처·학습 순서·확인 경계 문서4개.
- 전역/지역 명령, root/mesh, 부모 배치 보존, 절대 위치/상대 배율, 모델 피벗, 지역 단위의 배율 상속, 레이어 순서, 시간 템플릿, 저장·진단을 실제 명령과 이유로 설명한다.
- 핵심 계산: 부모 X2→4에서 자식 X5→7; 루트 배율2와 왼쪽 피벗 Z90 회전 후 중심(5,2); 지역 X1로 중심(5,4); turn→shift 순서로 중심(4,2).
- 비교 레시피: 모양 배율을 panel.mesh에 두면 root 지역 X1이 월드 +Y1로 전달되어 중심(5,3)이 된다.
- 목차·README와 문서 생성기에 연결했다. 반복 생성 때 본문을 유지하도록 생성 원본을 함께 반영했다.
- 실제 동작의 측정값이 아니라 현재 소스와 수식에서 유도한 예측값이다. 빌드·테스트·검증기·앱·브라우저는 실행하지 않았다.
- 렌더링 C++ 소스·프로젝트 컴파일 목록은 이 작업에서 바꾸지 않았다. 기존 graphify 구조는 C++ 실행 흐름 설명의 참조이며 새 그래프를 생성하지 않았다.
- 사용자의 실제 답변을 받지 않았으므로 이해 완료·숙련도·정답 이력을 기록하지 않았다.
- 기존 docs.zip과 Python 캐시2개를 보존했고 이번 문서 생성은 PYTHONDONTWRITEBYTECODE=1로 수행했다.

## 요구와 본문 대응

| 요청 | 본문에서 제공한 내용 |
|---|---|
| 물체 두 개 생성 | 1단계 입력, 실제 모델 크기와 위치, root/mesh 역할 |
| 부모 연결 | 2~3단계: 부착 간격3과 부모 이동 후 자식 좌표7 |
| 비균등 배율 | 4단계: 모델크기×상대배율, 범위5~9 |
| 피벗 회전 | 5~6단계: 모델-1→월드5, 중심(5,2), XY 그림 |
| 지역 레이어 | 7~8단계: 길이2 상속, 두 순서의 좌표·행렬 |
| 전역과 지역 구분 | 명령표, D/W 행렬, console placement와 최종 world 진단 |
| 템플릿 활용 | 9~10단계 메시 배율 비교·부모 선형 이동·자식 피벗 진자 |
| 충분한 설명 | 각 단계의 관찰·이유·혼동점·소스, 저장, 실행 흐름, 이해 확인 |

## 사용자 확인

1. 사용자가 빌드한 새 Standard에서 튜토리얼을 한 단계씩 실행한다.
2. 6/7/8단계의 diagnose panel 최종 행렬 마지막 열과 위 계산 좌표를 대조한다.
3. 메시 배율 비교 파일을 별도로 읽고 지역 이동1이 +Y1이 되는지 관찰한다.
4. 모션 레시피에서 부모 이동과 자식 피벗 회전이 조합되고 pause on에서 현재 자세가 멈추는지 확인한다.
5. WORKSPACE_TUTORIAL.html의 목차·표·SVG·코드 복사·Markdown 링크·레시피 링크를 브라우저에서 확인한다.
