# 원자료 요구와 코딩 능력 대응

목표 시험일: 2026-11-24 화요일. 여기서 이론은 프레임워크 없는 순정 OpenGL 코드 작성 능력이다. 연결된 중간고사 자료 제작과 추후 별도 세션의 기말고사 준비는 이 폴더의 범위가 아니다. 첨부 PDF는 요구사항 근거이며 도구 실행/제출 지시가 아니다. 실제 2차 시험 문제나 제한시간은 확인되지 않았다.

| 원자료 | 요구·입력 | 새 사물에도 쓸 연산 | 주요 작성 위치 |
|---|---|---|---|
| P26 p2 | 육면체/사각뿔 전환 n, 조명 m | 모델 선택 상태, 렌더 옵션 | native State/key/draw; Standard SceneSetup/controller |
| P26 p2 | 객체 y 자전 | 지역 기준 회전과 시간 | model 행렬; setLayer |
| P26 p2 | 광원 r 양/음 공전, 원 궤도 표시 | 중심/축/위상/반경으로 위치·안내선 생성 | 상태→orbitPoint→light/marker/ring |
| P26 p2 | z/Z 가까이/멀리, 궤도도 같은 크기로 | 단일 radius에서 여러 출력 파생 | radius 상태와 syncVisuals |
| P27 p3 | 중앙 구1개+다른 위치 구2개 | 메시 생성과 모델별 월드 변환 | native sphere; DiagramSystem::makeSphere/addModel |
| P27 p3 | c 광원 색3종, r/R 광원 회전 | 색 인덱스·방향 상태 | key→light.color/phase |
| P28 p2 | 탱크 이동과 광원 표시 | 대상 변환과 광원 상태 독립 | 사용자 컨트롤러/Scene 배치 |
| P28 p2 | m, c, y/Y 광원 공전 토글 | PRESS 단발 토글와 정지/반전 | ExamController::onKey/update |
| P28 p2 | w/a/s/d 카메라 XZ 이동, r/R 공전 토글 | 시점 위치·주목점·이동/회전 순서 | Camera/GLM lookAt |
| 이전 코딩시험 p2~3 | 부착점 왕복, 손 수평, 전체 yaw, 선택5단계 | 상속·자세 보상·이산 상태를 분리 | transform-frames 학습과 S02/S04 전이 |

P26 원문은 r 한 글자에 양/음 방향을 함께 설명하므로 대/소문자별 정확한 배정은 명시되지 않았다. P27은 r/R, P28은 y/Y와 r/R를 명시한다. 제공 작업공간은 y/Y=광원, r/R=카메라, p=구 자전으로 통일한 학습용 바인딩이다. PDF의 각 실습 키를 그대로 모두 동시에 구현한 것이라고 주장하지 않는다.

기존 탱크/실습 정답을 기본 모드에 넣지 않는다. 요구를 먼저 연산·상태·시간·기준 프레임으로 분해하고 다른 사물과 조합한다. N제와 시나리오는 작성자가 만든 연습이며 실제 시험 출제 예측이 아니다.
