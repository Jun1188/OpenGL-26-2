# CT2-S06 · 제한 시간 종합: 방사형 차단문과 경고등

경로: standard · 권장 55분(실제 시험 시간 아님)

## 문제

해설을 닫고 요구만 읽어 55분 연습한다. 세 차단문을 120도 간격으로 배치한다. j로 선택문을 순환하고 k로 선택문 열림/닫힘을 토글한다. 각 문은 자기 안쪽 경첩에서 Z축 0~70도로 45도/초 회전한다. 하나라도 실제 각도가 1도보다 크면 경고등이 0.5초마다 켜졌다 꺼진다. 닫힘 목표로 바꿔도 문이 닫히기 전에는 경고를 유지한다. F2에 다섯 번째 출력으로 확산 밝기 0.5 이상인 부분만 흰색으로 표시하는 임계값 모드를 추가한다.

## 상태·공간 설계

selected, targetOpen[3], angle[3], elapsed. 경고는 목표값이 아니라 실제 angle에서 파생한다. 객체/입력/갱신/광원/셰이더를 순서대로 작성한다. 시간 55분은 저자가 정한 연습 조건이며 실제 시험 시간은 미확인이다.

## 단계별 힌트

1. 회전문 크기와 피벗은 지역 좌표로 정한다. 문마다 동일 레이어 이름을 사용할 수 있다.
2. 경고등의 on/off는 intensity=0/2로 표현한다. 새 광원 종류를 만들지 않는다.

## 해설과 수정 코드

SceneSetup.cpp에 추가한다. 세 문은 각 지역 +X 방향으로 뻗는다.
```cpp
for(int i=0;i<3;++i) {
    const float a=glm::radians(120.f*i);
    graphics::ObjectSetup door;
    door.size={1.6f,.7f,.15f}; door.pivot={-.8f,0,0};
    door.position={.5f*std::cos(a),1,-.5f*std::sin(a)};
    door.rotationDegrees.y=120.f*i;
    door.material.color={.2f,.6f,.8f};
    const auto name="door"+std::to_string(i);
    scene.addObject(name,door);
    graphics::LayerSetup hinge; hinge.pivot={-.8f,0,0};
    scene.addLayer(name,"open",hinge);
}
graphics::PointLight alarm; alarm.position={0,3,0};
alarm.color={1,.1f,.1f}; alarm.intensity=0; scene.addLight("alarm",alarm);
```
State에 아래를 추가한다. std::array는 기존 헤더에 포함되어 있다.
```cpp
std::array<float,3> doorAngles{};
std::array<bool,3> targetOpen{};
int selected=0;
double elapsed=0;
```
onKey PRESS 구간에 추가한다.
```cpp
if(key==GLFW_KEY_J) state_.selected=(state_.selected+1)%3;
if(key==GLFW_KEY_K) state_.targetOpen[state_.selected]=!state_.targetOpen[state_.selected];
```
update에 추가한다.
```cpp
state_.elapsed+=dt; bool warning=false;
for(int i=0;i<3;++i) {
    auto& angle=state_.doorAngles[i];
    const float goal=state_.targetOpen[i] ? 70.f:0.f;
    angle+=std::clamp(goal-angle,-45.f*dt,45.f*dt);
    warning=warning || angle>1;
    graphics::LayerSetup h; h.pivot={-.8f,0,0}; h.rotationDegrees.z=angle;
    scene_.setLayer("door"+std::to_string(i),"open",h);
}
auto alarm=scene_.light("alarm");
alarm.intensity=warning && std::fmod(state_.elapsed,1.0)<.5 ? 2.f:0.f;
scene_.setLight("alarm",alarm);
```
F2 토글의 `%4`를 `%5`로 바꾼다. 외부 FragmentShader.glsl에서 uStudyView==3 분기 바로 다음, 합성 else 앞에 넣는다.
```glsl
else if (uStudyView == 4) color.rgb = vec3(step(0.5, dot(diffuse, vec3(0.2126,0.7152,0.0722))));
```
이 모드는 재질색을 곱하기 전 diffuse 에너지의 가중합을 판정한다. 감마 보정된 화면색의 물리 휘도를 측정한다고 설명하지 않는다. 경고 표시 물체가 추가 조건이면 unlit 작은 구를 만들고 intensity 상태와 같은 조건으로 tint를 갱신한다. 현재 요구의 경고는 조명의 켜짐이다.

## 사용자가 확인할 결과

- [ ] F2 새 분기에서 문 실루엣은 유지되고 밝기 임계값만 바뀐다.
