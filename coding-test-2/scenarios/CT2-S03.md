# CT2-S03 · 분류 게이트: 연속 이동과 이산 전환

경로: native · 권장 60분(실제 시험 시간 아님)

## 문제

세 화물이 한 방향으로 이동하는 분류 라인을 만든다. j로 선택 화물을 순환하고 k로 선택 화물의 행선지(왼쪽/오른쪽)를 전환한다. 분기점 x=0을 통과하면 선택 상태와 무관하게 그때 확정한 행선지를 따라 움직인다. 끝점 x=4에서 초기 위치로 돌아와 새 회차를 시작한다. 화물 색은 행선지, specular는 선택 여부를 나타낸다.

## 상태·공간 설계

각 화물은 x,route(-1/+1),latchedRoute,latched를 가진다. 선택과 경로 확정은 다른 상태다. 직선 이동 x<0, 분기 후 z=route*min(x,2)/2로 정의한다. 이 문제는 충돌/운송 물리 모델이 아닌 지정 경로 애니메이션이다.

## 단계별 힌트

1. 분기 후 키를 눌렀다고 이미 진행 중인 화물의 궤도를 바꾸면 조건 위반이다.
2. 화물이 wrap될 때 latched=false로 되돌린다.

## 해설과 수정 코드

main.cpp에 Parcel 정의를 State 앞에 추가하고 State에 배열과 선택을 추가한다.
```cpp
struct Parcel { float x; int route=1,latchedRoute=1; bool latched=false; };
// State 안
std::array<Parcel,3> parcels{{{-4},{-2.7f},{-1.4f}}};
int selected=0;
```
key의 PRESS 구간에 넣는다.
```cpp
if(key==GLFW_KEY_J) state.selected=(state.selected+1)%3;
if(key==GLFW_KEY_K) state.parcels[std::size_t(state.selected)].route*=-1;
```
update의 pause 확인 뒤에 넣는다.
```cpp
for(auto& p:state.parcels) {
    p.x+=1.2f*dt;
    if(p.x>=4) { p.x-=8; p.latched=false; }
    if(!p.latched && p.x>=0) { p.latchedRoute=p.route; p.latched=true; }
}
```
렌더 루프의 기존 중심 물체와 옆 구 draw를 다음으로 교체한다. 바닥·광원·uniform은 보존한다.
```cpp
for(int i=0;i<3;++i) {
    const auto& p=state.parcels[std::size_t(i)];
    const int route=p.latched ? p.latchedRoute:p.route;
    const float z=p.x<0 ? 0.f : route*std::min(p.x,2.f)*.5f;
    auto model=glm::scale(glm::translate(glm::mat4(1),glm::vec3(p.x,0,z)),glm::vec3(.6f));
    scalar(shader,"Ks",i==state.selected ? 1.f:0.f);
    draw(shader,meshes[0],model,route>0 ? glm::vec3(.2f,.8f,.4f):glm::vec3(.9f,.3f,.2f));
}
scalar(shader,"Ks",.8f); // 뒤의 다른 물체에 선택 재질을 남기지 않음
```
기본 dt는 .05초 이하로 제한된다. 이 모델은 한 프레임에 여러 회차를 건너뛰는 큰 시간간격을 다루지 않는다. 임의 큰 dt를 허용할 새 조건이라면 경계 사건을 시간 순으로 처리하거나 작은 단계로 나눈다.

## 사용자가 확인할 결과

- [ ] 분기 전 k는 경로를 바꾸고 분기 후 k는 다음 회차의 route만 바꾼다.
- [ ] Space 정지 중 선택·행선지 변경이 가능하고 위치는 멈춘다.
- [ ] 배열 인덱스와 화물 상태를 분리해 선택해도 위치가 점프하지 않는다.
