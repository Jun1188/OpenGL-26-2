# CT2-S01 · 회전 전시대: 같은 위치, 다른 광원 프레임

경로: native · 권장 60분(실제 시험 시간 아님)

## 문제

전시대에 세 작품을 원형으로 배치한다. 전시대는 Y축 회전하며 작품은 자기 축으로도 회전한다. l키로 광원을 월드 고정↔전시대 부착으로 전환한다. 전환 순간 위치는 유지한다. 새 프레임워크 API 없이 model과 lightPosition uniform으로 해결한다. 재질은 작품마다 다른 Ks를 갖게 한다.

## 상태·공간 설계

상태 deckAngle, attached, lightCoordinate. attached=false일 때 lightCoordinate는 월드, true일 때 전시대 지역 좌표다. 전환은 inverse(newFrame)*oldWorldPoint. 전시대 회전과 작품 자전은 서로 다른 행렬 위치다.

## 단계별 힌트

1. M=Rdeck*T(offset)*Rself*S로 시작한다.
2. lightCoordinate 값을 새 좌표계에 맞게 변환하지 않으면 전환 때 점프한다.

## 해설과 수정 코드

기존 State에 다음 필드를 추가한다.
```cpp
double deckAngle=0;
bool attached=false;
glm::vec3 lightCoordinate{2,4,3};
```
key의 PRESS 구간에 추가한다. 키 전환 시점의 전시대 행렬로 재표현한다.
```cpp
if(key==GLFW_KEY_L) {
    const auto deck=glm::rotate(glm::mat4(1),glm::radians(float(state.deckAngle)),glm::vec3(0,1,0));
    const auto world=state.attached ? deck*glm::vec4(state.lightCoordinate,1)
                                    : glm::vec4(state.lightCoordinate,1);
    state.attached=!state.attached;
    state.lightCoordinate=glm::vec3(state.attached ? glm::inverse(deck)*world : world);
}
```
update에서 pause 확인 뒤 deckAngle+=20*dt를 추가한다. 기존 y/z 광원 제어는 이 시나리오에서는 사용하지 않는다. 렌더에서 기존 중심 물체·옆 구·광원 marker·궤도 draw를 빼고 다음으로 대체한다(바닥 draw는 유지해도 된다). 이 코드는 기존 view/projection/기본 uniform 전송 뒤다.
```cpp
const auto deck=glm::rotate(glm::mat4(1),glm::radians(float(state.deckAngle)),glm::vec3(0,1,0));
const auto light=state.attached ? glm::vec3(deck*glm::vec4(state.lightCoordinate,1)) : state.lightCoordinate;
vector(shader,"lightPosition",light);
for(int i=0;i<3;++i) {
    const float a=float(2*pi*i/3);
    const auto offset=glm::vec3(2*std::cos(a),.5f,2*std::sin(a));
    const auto self=glm::rotate(glm::mat4(1),glm::radians(float(state.objectDegrees)+30*i),glm::vec3(0,1,0));
    auto model=deck*glm::translate(glm::mat4(1),offset)*self*
        glm::scale(glm::mat4(1),glm::vec3(1,.5f,1.4f));
    scalar(shader,"Ks",.2f+.3f*i);
    draw(shader,meshes[std::size_t(i)],model,{.3f+.2f*i,.7f,.9f-.2f*i});
}
draw(shader,meshes[0],glm::scale(glm::translate(glm::mat4(1),light),glm::vec3(.15f)),colors[state.color],true);
```
기존 objectDegrees와 pause 갱신을 재사용한다. p는 작품 자전, Space는 정지다. 프레임 전환은 표시 위치를 보존하지만 이후 궤도는 달라진다. 질량이나 회전 관성은 모델링하지 않았다.

## 사용자가 확인할 결과

- [ ] l 전환 직전/직후 광원 표시는 같은 위치다.
- [ ] 월드 고정일 때 작품이 광원 앞을 지나고, 부착일 때 같이 돈다.
- [ ] 작품 자전을 꺼도 전시대 공전은 계속된다.
