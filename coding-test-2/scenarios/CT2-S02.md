# CT2-S02 · 접이식 차양: 모서리 경첩과 부착 조명

경로: standard · 권장 60분(실제 시험 시간 아님)

## 문제

가로로 나열된 네 차양판을 만든다. h를 누르면 각 판이 0~60도로 열리고 놓으면 닫힌다. 각 판은 자기 뒤 모서리가 고정된다. 첫 판에 부착된 등이 함께 회전하며, 표시 물체는 최종 광원 위치와 일치한다. 인접 판의 시작 각도에는 10도씩 위상차를 준다.

## 상태·공간 설계

공통 openAngle과 판별 clamp(openAngle-10*i,0,60). 판 모델의 반깊이는 1, 지역 경첩은 z=-1. world position은 경첩 anchor다. 부착광은 awningLamp 이름으로 key와 분리한다. 기존 controller는 key만 제어하므로 충돌하지 않는다.

## 단계별 힌트

1. 판의 중심을 (x,2,1)에 고정하는 대신 피벗을 (0,0,-1), anchor를 (x,2,0)로 둔다.
2. 표시 물체는 root로 두고 최종 월드 좌표만 반영할 수 있다.

## 해설과 수정 코드

SceneSetup.cpp의 insert 앞에 추가한다.
```cpp
for(int i=0;i<4;++i) {
    graphics::ObjectSetup p;
    p.size={1,.1f,2}; p.position={-1.65f+1.1f*i,2,0}; p.pivot={0,0,-1};
    p.material.color={.3f,.6f,.8f};
    const auto name="awning"+std::to_string(i);
    scene.addObject(name,p);
    graphics::LayerSetup hinge; hinge.pivot={0,0,-1};
    scene.addLayer(name,"fold",hinge);
}
graphics::PointLight lamp; lamp.position={0,.3f,1};
lamp.color={1,.8f,.3f}; lamp.intensity=1;
scene.addLight("awningLamp",lamp,"awning0");
graphics::ObjectSetup marker; marker.size={.1f,.1f,.1f}; marker.material.unlit=true;
marker.material.color=lamp.color; scene.addObject("awningMarker",marker);
```
ExamController State에 `float openAngle=0;`를 추가한다. 클래스에 bool awningHeld_=false를 추가하고 initialize/reset/focus 상실 때 false로 한다. onKey의 PRESS 필터 앞에 `if(key==GLFW_KEY_H) awningHeld_=action!=GLFW_RELEASE;`를 넣는다. update에 추가한다.
```cpp
state_.openAngle=std::clamp(state_.openAngle+(awningHeld_ ? 40.f:-40.f)*dt,0.f,90.f);
for(int i=0;i<4;++i) {
    graphics::LayerSetup hinge; hinge.pivot={0,0,-1};
    hinge.rotationDegrees.x=-std::clamp(state_.openAngle-10.f*i,0.f,60.f);
    scene_.setLayer("awning"+std::to_string(i),"fold",hinge);
}
```
Console::onRender에서 scene_.syncTools 뒤에 표시 위치를 갱신한다.
```cpp
auto& raw=app_.getScene();
const auto frame=raw.worldMatrix(scene_.object("awning0"));
if(!frame) return false;
const auto pos=glm::vec3(*frame*glm::vec4(0,.3f,1,1));
if(!raw.setWorldPlacement(scene_.object("awningMarker"),glm::translate(glm::mat4(1),pos))) return false;
```
표시 물체는 지역 레이어가 없고 unlit이다. 네 판의 마지막 각도는 모두 60도지만 열리기 시작하는 시점은 다르다. 회전법칙을 직접 정한 애니메이션이다.

## 사용자가 확인할 결과

- [ ] h를 누르면 첫 판부터 순차적으로 열린다.
- [ ] 반대 모서리는 움직이고 뒤 경첩은 고정된다.
- [ ] 조명 표시와 광원이 판 회전 뒤에도 일치한다.
