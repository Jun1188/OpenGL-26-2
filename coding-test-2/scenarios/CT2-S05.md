# CT2-S05 · 반복 조형물: 패턴과 비균등 법선

경로: native · 권장 60분(실제 시험 시간 아님)

## 문제

16개의 조형물을 방사형으로 배치한다. t로 4×4 격자↔방사형을 전환한다. 각 물체는 자기 위상에 따라 높이가 진동하고 비균등 배율을 가진다. 패턴 전환과 조명 공전은 독립이다. 배열에 16개 좌표를 직접 써 넣지 않는다. F2 법선 출력으로 변환을 확인한다.

## 상태·공간 설계

패턴은 i→position 함수다. 시간은 누적 simulationSeconds, 물체별 phase=2πi/16. 물체 월드 행렬은 T(position)*Ry(localAngle)*S. 이는 위치를 공식으로 정한 절차 애니메이션이며 힘 시뮬레이션이 아니다.

## 단계별 힌트

1. 격자는 column=i%4,row=i/4다. 중심을 맞추려면 1.5를 뺀다.
2. 위상은 프레임 수가 아니라 시간에 더한다.

## 해설과 수정 코드

State에 `bool grid=false; double simulationSeconds=0;`를 추가한다. key PRESS 구간에서 T를 토글한다. update의 pause 확인 다음에 simulationSeconds+=dt를 추가한다. 렌더의 중심 물체와 옆 구 draw를 다음으로 대체한다.
```cpp
for(int i=0;i<16;++i) {
    const float phase=float(2*pi*i/16);
    const float height=.5f+.4f*std::sin(float(state.simulationSeconds)*2+phase);
    glm::vec3 pos;
    if(state.grid) pos={(i%4-1.5f)*1.5f,height,(i/4-1.5f)*1.5f};
    else pos={3*std::cos(phase),height,3*std::sin(phase)};
    const auto model=glm::translate(glm::mat4(1),pos)*
        glm::rotate(glm::mat4(1),float(state.simulationSeconds)+phase,glm::vec3(0,1,0))*
        glm::scale(glm::mat4(1),glm::vec3(.6f,1.3f,.35f));
    draw(shader,meshes[2],model,{.2f+.6f*i/15,.7f,.9f-.5f*i/15});
}
```
normalMatrix는 기존 draw에서 각 model의 역전치로 계산된다. 같은 GPU 구 메시를 16회 재사용한다. 16개 VBO를 새로 만들지 않는다. 이 예제는 인스턴스 렌더링이 아닌 반복 draw다. 패턴 전환 시 위치가 즉시 달라지는 것이 명시된 동작이다. 보간 전환이 추가 조건이면 old/new 패턴 위치와 transitionProgress를 별도 상태로 둔다.

## 사용자가 확인할 결과

- [ ] T가 16개 전체 배치를 바꾸고 개별 위상은 보존한다.
- [ ] Space 정지 때 높이와 자전은 멈춘다.
- [ ] 비균등 배율에서도 구의 법선 출력이 매끈하다.
