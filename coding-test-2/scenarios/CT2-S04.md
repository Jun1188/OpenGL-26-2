# CT2-S04 · 이동 촬영 장치와 수평 모니터

경로: standard · 권장 60분(실제 시험 시간 아님)

## 문제

촬영 장치가 반지름 3의 원형 경로를 이동한다. 본체는 경로 접선 방향을 향한다. 모니터는 본체의 지역점 (0,1,0)에 붙은 위치만 따라가며 화면 수직축은 월드 Y를 유지한다. 카메라는 본체 지역 오프셋 (0,1.2,-2)에서 원점 부근 표적 (0,1,0)을 본다. 회전 정지와 광원 공전 정지를 별도로 제어한다.

## 상태·공간 설계

경로 위상과 자세 yaw를 분리한다. 정지 토글은 h, 기존 y는 광원용이다. 모니터는 본체의 방향과 배율을 물려받지 않는 루트 객체다. 카메라는 하나의 컨트롤러만 소유해야 한다.

## 단계별 힌트

1. 접선은 (-sin(theta),0,cos(theta))다. +Z가 진행 방향이면 yaw=-theta(라디안 기준)로 나타낼 수 있다.
2. 접선과 실제 atan2(x,z)로 방향을 구하면 부호를 추측할 필요가 없다.

## 해설과 수정 코드

SceneSetup.cpp에 rig와 monitor를 루트 객체로 추가한다.
```cpp
graphics::ObjectSetup rig; rig.size={.8f,.4f,1.2f}; rig.position={3,0,0};
scene.addObject("rig",rig);
graphics::ObjectSetup monitor; monitor.size={.8f,.5f,.08f};
monitor.material.unlit=true; monitor.material.color={.2f,.8f,.9f};
scene.addObject("monitor",monitor);
```
ExamController State에 `double rigPhase=0; bool rigMoving=false;`를 추가한다. onKey PRESS 구간에 `if(key==GLFW_KEY_H) state_.rigMoving=!state_.rigMoving;`를 넣는다. 기존 update의 `auto movement=...`부터 카메라 공전 결과 대입까지의 블록을 아래로 교체한다. key의 WASD/r 상태는 이 시나리오에서 쓰지 않는다고 help도 고친다.
```cpp
state_.rigPhase+=state_.rigMoving ? .4*dt:0;
const float a=float(state_.rigPhase);
const glm::vec3 pos{3*std::cos(a),0,3*std::sin(a)};
const glm::vec3 tangent{-std::sin(a),0,std::cos(a)};
const float yaw=std::atan2(tangent.x,tangent.z);
const auto W=glm::translate(glm::mat4(1),pos)*
    glm::rotate(glm::mat4(1),yaw,glm::vec3(0,1,0));
if(!app_.getScene().setWorldPlacement(scene_.object("rig"),W))
    throw std::runtime_error("rig placement");
state_.camera.position=glm::vec3(W*glm::vec4(0,1.2f,-2,1));
state_.camera.target={0,1,0}; state_.camera.up={0,1,0};
```
기존 아래쪽 scene_.setCamera(state_.camera)는 유지한다. rig에 별도 authoring layer나 native motion을 추가하지 않는 조건이다. 모니터는 Console::onRender에서 syncTools 뒤 갱신한다.
```cpp
auto& raw=app_.getScene();
const auto W=raw.worldMatrix(scene_.object("rig"));
if(!W) return false;
const auto p=glm::vec3(*W*glm::vec4(0,1,0,1));
if(!raw.setWorldPlacement(scene_.object("monitor"),glm::translate(glm::mat4(1),p))) return false;
```
모니터가 화면을 항상 카메라로 향하는 billboard라는 조건은 없다. 월드 XY 방향을 유지한다. 카메라만으로 확인하기 힘들면 시험용 고정 시점을 별도 키로 전환하되 두 카메라를 동시에 쓰지 않는다.

## 사용자가 확인할 결과

- [ ] 본체는 경로 접선을 향하고 모니터는 본체 yaw를 따라 돌지 않는다.
- [ ] h로 촬영 장치를 멈춰도 y 광원 공전은 계속된다.
- [ ] viewPosition이 실제 카메라를 따라 바뀌어 정반사도 변한다.
