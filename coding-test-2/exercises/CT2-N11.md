# CT2-N11 · 광원 색과 재질 색의 조합

경로: standard · 권장 30분(실제 시험 시간 아님)

## 문제

붉은 판과 흰 판을 나란히 둔다. 붉은/푸른 광원에서 어떤 항이 사라지는지 예측한다. Ka, Kd, Ks, N을 하나씩 바꾸며 F2 출력을 비교한다. 조명 off와 unlit 물체가 같은 설정인지 구분한다.

## 상태·공간 설계

광원 RGB와 재질 RGB는 곱해진다. 독립 주변광은 광원 색 변화와 별개다. Standard 점광원 정반사는 현재 구현에서 재질 색으로도 tint된다. 물리 기반 백색 specular로 가정하지 않는다.

## 단계별 힌트

1. SceneSetup에 두 ObjectSetup을 복사하되 이름과 position을 다르게 쓴다.
2. 방향광은 기본값 0이다. ambient도 0으로 두고 점광원 확산만 먼저 비교한다.

## 해설과 수정 코드

SceneSetup의 insert 앞에 넣는다.
```cpp
graphics::ObjectSetup swatch;
swatch.size={1,1,.2f}; swatch.position={-2,1,0};
swatch.material.color={1,0,0};
swatch.material.ambientStrength=0;
swatch.material.diffuseStrength=1;
swatch.material.specularStrength=0;
scene.addObject("redSwatch",swatch);
swatch.position={-3.5f,1,0}; swatch.material.color={1,1,1};
scene.addObject("whiteSwatch",swatch);
```
ExamController의 C 색 배열을 순수 백/적/청으로 바꾸면 비교가 분명하다.
```cpp
const graphics::GlColor colors[]={{1,1,1},{1,0,0},{0,0,1}};
```
F2 확산 모드에서 순수 붉은 재질×순수 푸른 빛은 0이다. 합성 모드에서 주변광이 남을 수 있으므로 위 재질 Ka=0으로 통제했다. 이후 Ka=.25, Ks=.8,N=8/128을 따로 바꿔 본다. render lighting=false는 장면 조명 계산을 생략한다. material.unlit=true는 그 물체만 조명 계산을 생략한다.

## 사용자가 확인할 결과

- [ ] 흰 판은 광원 색을 드러낸다.
- [ ] 푸른 빛 아래 붉은 판의 확산 항은 검다.
- [ ] unlit 표시 물체는 m에 따라 사라지거나 검게 변하지 않는다.
