# CT2-N03 · 법선을 고쳐 밝기 오류 찾기

경로: native · 권장 30분(실제 시험 시간 아님)

## 문제

구를 scale=(2,1,0.5)로 늘린다. normalMatrix를 mat3(model)로 바꾼 잘못된 버전과 역전치 버전을 비교한다. 조명은 고정하고 F2로 법선·확산·정반사를 관찰한다. N, L, V의 좌표계를 하나로 맞춰야 하는 이유를 설명한다.

## 상태·공간 설계

정점 위치는 월드, 법선은 월드, 광원·카메라 위치도 월드다. 법선은 표면 접선과 수직이라는 조건을 보존해야 한다. 구의 경사진 법선에서 오류가 잘 보인다.

## 단계별 힌트

1. 접선 t와 법선 n에 n·t=0을 적용한다.
2. A t에 수직인 새 법선은 transpose(inverse(A)) n이다.

## 해설과 수정 코드

`native/main.cpp`의 draw 함수에서 다음 행을 유지한다.
```cpp
const auto normal=glm::transpose(glm::inverse(glm::mat3(model)));
glUniformMatrix3fv(location(p,"normalMatrix"),1,GL_FALSE,glm::value_ptr(normal));
```
VertexShader.glsl에서 법선을 변환하고, 보간된 법선은 FragmentShader.glsl에서 다시 정규화한다.
```glsl
// vertex
worldNormal = normalMatrix * normal;
// fragment
vec3 N = normalize(worldNormal);
vec3 L = normalize(lightPosition - worldPosition);
vec3 V = normalize(viewPosition - worldPosition);
```
잘못된 normal=mat3(model)을 임시로 넣었다가 원래 식으로 복구한다. 두 배율이 같거나 축과 평행인 면만 보면 오류를 놓칠 수 있다. 판정은 비균등 구의 경사진 표면에서 한다.

## 사용자가 확인할 결과

- [ ] 법선 출력은 -1~1을 0~1로 매핑한 색이다.
- [ ] 광원이 표면 뒤로 가면 확산·정반사가 0이다.
- [ ] 동일한 화면을 보고 재질 값만 바꾸어 법선 오류를 숨기지 않는다.
