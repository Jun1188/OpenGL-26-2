## GLLIB-N01

### 접이식 표본 검사판

바닥에 받침대와 세로 판을 놓는다. 판의 중심은 경첩보다 0.6 아래에 있다. Space를 한 번 누르면 상단 경첩을 축으로 판이 0도에서 90도까지 회전한다. 움직이는 중에 다시 누르면 현재 각도에서 반대 목표를 향한다. 판 끝에 표시점을 붙인다. R로 초기 상태에 돌아간다.

- 배점 20점. 정적 형상 5, 경첩 고정 5, 목표 전환 5, 표시점·리셋 5.
- 확인. 0도·45도·90도에서 경첩 위치를 비교한다. 움직이는 중 Space를 두 번 누르고 끊김 없이 방향이 바뀌는지 본다.

<details>
<summary>힌트와 해설</summary>

경첩을 `scene.addGroup`으로 만들고 판과 표시점을 자식으로 등록한다. 경첩은 받침대 로컬 위치에 둔다. 경첩과 판의 부모를 먼저 정의한 뒤 판의 중심은 경첩 기준 `(0,-0.6,0)`에 둔다. 현재 각도는 프레임당 최대 `speed * dt`만 목표각 쪽으로 움직인다. 경첩 `Transform3D.rotation`만 바꾸므로 두 자식이 같은 기준점으로 회전한다. 직접 피벗을 쓰는 방식이면 중심 기준 판의 상단은 로컬 `(0,0.6,0)`이다. 그 점을 `localBasis`, 경첩 위치를 `basis`에 둔다.

</details>

## GLLIB-N02

### 극지 기지의 탐사 로버

로버를 바닥 위에서 방향키로 이동한다. A/D를 누르는 동안 로버가 Y축을 중심으로 돈다. 로버의 앞쪽에 카메라를 붙이고 V로 외부 시점과 장착 카메라를 바꾼다. 기지의 출발 지점은 모든 조작에서 제자리를 유지한다. 창이 포커스를 잃으면 눌린 키를 해제한다. R로 로버와 카메라를 초기 상태로 되돌린다.

- 배점 25점. 바닥·로버·출발 표지 5, 이동·회전 8, 장착 시점·전환 8, 포커스·리셋 4.
- 확인. 로버를 90도 돌린 뒤 장착 시점에서 이전에 앞에 있던 물체가 옆으로 이동하는지 본다. A를 누른 상태에서 창 포커스를 바꾼 뒤 회전이 계속되는지 확인한다.

<details>
<summary>힌트와 해설</summary>

로버 루트에 `position`, `yaw`를 적용하고 부품을 자식으로 둔다. 카메라 모델의 로컬 앞을 +Z로 정한다. 장착 시점의 로컬 위치를 예를 들어 `(0,0.7,0.4)`, 로컬 주목점을 `(0,0.7,2)`로 두면 두 점의 차이가 앞 방향이다. `scene.worldMatrix(root)`를 확인한 뒤 `CameraSystem::attached(local, *world)`를 사용한다. 자세를 적용한 뒤 카메라를 계산한다. 외부 시점은 고정 `Camera`를 보관해 V로 복귀한다. PRESS/RELEASE는 기존 `GLFW_PRESS` 필터 앞에서 처리하고 `onFocus(false)`에서 지운다.

</details>

## GLLIB-N03

### 회전 무대의 드럼 운반기

회전 무대 위에 두 드럼을 반대편에 올린다. 무대와 드럼은 기본 도형으로 단순화한다. T는 무대의 공전을 시작·정지한다. S는 무대 위에 있는 선택된 드럼의 자전을 시작·정지한다. 운반을 시작한 드럼은 그때의 자세를 유지한다. 1/2로 대상을 선택한다. G를 누르면 선택된 드럼이 현재 위치에서 무대 밖의 고정 받침대로 1초간 이동한다. 내려놓기 시작한 드럼은 무대가 계속 돌아도 바깥 받침대로 향한다. R로 모든 위치·속도·선택을 복원한다.

- 배점 30점. 정적 배치 5, 공전·선택 8, 자전 분리 5, 위치 점프 없는 인계 8, 리셋 4.
- 확인. 무대가 돌 때 G를 누른다. 드럼이 멀리 순간이동하지 않고 지정 위치에 도착하는지, 남은 드럼은 계속 무대를 따르는지 본다.

<details>
<summary>힌트와 해설</summary>

공전은 그룹에, 자전은 드럼에 둔다. 드럼의 메시 로컬 원점을 중심으로 잡고 자전은 기본 SRT 회전으로 표현한다. 출발 순간에 `placementMatrix`로 월드 배치를 저장한다. 네 번째 열의 xyz가 이 예시의 월드 중심이다. `setParentPreserveWorld(id, std::nullopt)`가 성공한 장면에서 부모 연결이 끊긴다. 이 API는 현재 월드 배치를 유지하지만 내부 attachment와 기본 SRT 표현이 남으므로, 이동 중에는 시작 월드 배치에서 이동 성분만 바꿔 `setWorldPlacement`로 적용하는 방법이 확실하다. 시간은 `clamp(elapsed / 1.0f, 0.0f, 1.0f)`. 리셋은 부모, attachment, 초기 SRT까지 함께 되돌린다. 단순 해법으로 R에서 `scene.clear()` 후 초기 장면과 ID를 다시 만든다.

</details>

## GLLIB-N04

### 수족관의 먹이 투입기

바닥에 수조와 두 투입구를 표시한다. 투입구는 실린더를 만들 시간 대신 얇은 상자로 표시해도 된다. Space를 누르면 두 투입구를 번갈아 사용해 구형 먹이를 하나 떨어뜨린다. 먹이가 바닥에 닿으면 재사용 대기 상태가 된다. R로 먹이와 카메라를 초기화한다. 왼쪽은 원근 시점, 오른쪽은 위에서 보는 직각 투영이다. V를 누르면 전체 화면을 외부 시점으로 전환한다. 시작과 정지에서 두 뷰의 먹이 상태가 일치해야 한다.

- 배점 30점. 정적 배치·구형 먹이 6, 생성·낙하·재사용 10, 두 뷰 10, 전환·리셋 4.
- 확인. 먹이 한 개를 떨어뜨리고 두 뷰에서 같은 순간 같은 수조로 들어가는지 비교한다. 창 크기를 바꾸고 화면을 좌우로 나누는 경계를 확인한다.

<details>
<summary>힌트와 해설</summary>

먹이 위치와 사용 여부는 하나의 장면 상태에서만 갱신한다. 사용하지 않는 슬롯은 `setVisible(id, false)`로 숨긴다. `main`에서 `setRenderHandler`를 등록하고 `renderViews`에 두 패스를 넘긴다. 크기는 `getFramebufferSize()`로 읽고 분할 너비를 계산한다. 상단 뷰를 `position=(0,8,0), target=(0,0,0), up=(0,0,-1)`로 두면 시선과 up이 평행하지 않다. 첫 패스와 둘째 패스의 뷰포트는 겹치지 않게 지정한다. 렌더 콜백에서 먹이 위치를 갱신하는 동작은 넣지 않는다.

</details>

## GLLIB-N05

### 비와 우산 · 100분 모의 실습

바닥은 XZ 평면이고 위는 +Y다. 우산 받침을 방향키로 XZ에서 이동한다. 받침에는 손잡이와 막대, 상단에는 접이식 살 4개가 있다. 기준점, 색상, 크기는 판별 가능하게 정한다. 조명은 기본값을 사용한다.

| 관찰 항목 | 점수 |
| --- | ---: |
| 바닥·막대·살 네 개·빗방울을 화면에 표시한다. | 20 |
| 방향키로 받침을 이동하고 A/D를 누르는 동안 우산이 Y축으로 회전한다. 빗방울은 받침의 변환을 따르지 않는다. | 20 |
| Space로 접힘·펼침을 토글한다. 각 살이 상단 경첩을 기준으로 회전하며 도중에 반전할 수 있다. | 25 |
| 빗방울을 월드에서 낙하시킨다. 바닥에 닿으면 다시 위로 올린다. 완전히 펼친 상태에서는 지붕 높이를 통과하는 방울 중 우산 반경 안에 든 방울도 위로 올린다. | 20 |
| V로 외부 시점과 우산 장착 시점을 오가고, R로 전체 초기 상태를 복구한다. Q 또는 Esc로 종료한다. | 15 |

시험 예측 없이 100분을 연습 타이머로 사용한다. 20분까지 띄울 장면을 정하고 55분까지 이동·펴기까지 연결한다. 85분까지 비와 카메라를 넣고 마지막 15분에 항목별로 화면을 대조한다. 시간 부족 시 방울 수, 외형의 세부 묘사, 빛 효과부터 줄인다.

<details>
<summary>힌트와 해설</summary>

- 계층은 받침 루트 → 꼭대기 그룹 → 방위각 그룹 4개 → 각 경첩/살이다. 위에서 본 방향은 90도씩 다르게 둔다. 1개 살에서 경첩 위치가 고정되는지 본 뒤 복제한다.
- 초기 살 모델을 경첩 기준 `-Y` 방향으로 길게 배치한다. 예를 들어 X축에 대한 -75도 회전은 이 살을 +Z 쪽으로 거의 수평으로 편다. 방위각 그룹이 서로 다른 방향을 만든다. 모든 살에 같은 현재 펼침 각도를 적용한다.
- 비는 부모가 없는 슬롯 배열이다. 매 프레임 이전 높이와 현재 높이를 보관한다. `prevY > roofY && y <= roofY`에서만 반경을 검사한다. 반경은 `dx*dx + dz*dz <= r*r`. 이번 연습은 수평 원판으로 판정 영역을 단순화한다. 방울이 바닥을 통과한 경우도 같은 재사용 함수로 처리한다.
- 권장 적용 순서는 입력 상태 → 받침과 경첩 변환 → 빗방울 갱신 → 필요 시 부착 카메라다. `setPosition`의 인자는 부모가 있는 엔티티에서는 부모 기준이다.
- R에서 각도·목표·받침 위치·시점·방울 위치·눌린 키를 복구한다. 카메라 전환이 비의 시간에 영향을 주지 않는지 확인한다.

</details>
