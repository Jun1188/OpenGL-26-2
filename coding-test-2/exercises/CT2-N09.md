# CT2-N09 · 부착 광원과 표시 물체 동기화

경로: standard · 권장 35분(실제 시험 시간 아님)

## 문제

key 광원을 panel에 부착한다. 광원은 panel 지역 좌표에서 공전한다. 표시 물체와 원 궤도가 최종 월드 위치에서 광원과 일치해야 한다. 광원의 지역 위치와 렌더러가 받는 월드 위치를 구별한다.

## 상태·공간 설계

SceneAuthoring은 parent 이름과 PointLight의 지역 값을 저장한다. syncTools가 부모 최종 행렬로 광원을 변환한다. ExamController는 lightParent를 유지하며, syncVisuals에서 같은 부모 행렬을 사용한다.

## 단계별 힌트

1. SceneSetup의 addLight 세 번째 인수가 parent다.
2. 빛 위치뿐 아니라 궤도도 같은 frame으로 옮긴다. 비균등 부모라면 원이 월드에서 타원이 될 수 있다.

## 해설과 수정 코드

SceneSetup.cpp의 light key 구획에서 등록을 바꾼다.
```cpp
cfg_key.position={2.f,1.f,0.f};
scene.addLight("key",cfg_key,"panel");
```
ExamController는 initialize에서 위 지역 위치를 읽어 radius=2,height=1,phase=0으로 시작한다. update는 계속 같은 parent를 setLight에 넘긴다. 최종 순서는 다음과 같다.
```cpp
// Console::onRender: Application의 Scene 모션 갱신 뒤 호출됨
scene_.syncTools();
controller_.syncVisuals();
return app_.renderScene();
```
지역 궤도 q와 부모 월드행렬 W에 대해 markerWorld=W*vec4(q,1)이다. renderer의 pointLights에도 같은 위치가 들어가야 한다. 기존 구현에 이 식이 있으므로 두 번째 광원 컨트롤러를 중복 추가하지 않는다. 부모에 비균등 배율이 있다면 원은 월드에서 타원이 된다. 월드에서 원이어야 한다는 새 조건이면 광원 자체를 월드 좌표로 제어하거나 부모에서 위치·회전만 추출하는 별도 프레임을 설계한다.

## 사용자가 확인할 결과

- [ ] panel 회전과 광원 공전을 동시에 해도 표시 물체가 광원 위치를 따른다.
- [ ] z/Z가 지역 반경을 바꾼다.
- [ ] 최종 프레임 동기화 전 값을 쓰면 한 프레임 지연이 생길 수 있음을 설명한다.
