# CT2-N08 · 부모 위치만 따르는 수평 받침대

경로: standard · 권장 40분(실제 시험 시간 아님)

## 문제

회전하는 panel의 끝점을 따라가는 받침대를 만든다. 받침대 중심은 끝점 위치를 따라가지만, panel의 기울기와 비균등 배율은 상속하지 않는다. 다른 객체의 방향을 상속하지 않는 조건을 부모 연결 하나로 해결하려 하지 않는다.

## 상태·공간 설계

받침대는 월드 루트 객체다. panel 지역점→panel 최종 월드 행렬로 위치만 계산한다. 받침대의 세계 방향과 배율은 독립적으로 만든다. SceneAuthoring 및 Scene 모션의 최종 갱신 후 위치를 반영한다.

## 단계별 힌트

1. panel과 같은 parent로 등록하면 배율/회전도 상속한다.
2. T(end)*S(trayScale)를 새로 만든다. panelWorld 전체를 받침대에 곱하지 않는다.

## 해설과 수정 코드

SceneSetup.cpp의 끝에 먼저 등록한다.
```cpp
graphics::ObjectSetup tray;
tray.size={.7f,.15f,.7f}; tray.position={0,2,0};
tray.material.color={.7f,.8f,.3f};
scene.addObject("tray",tray); // parent 인수 없음
```
Console::onRender의 `scene_.syncTools()` 뒤, `controller_.syncVisuals()` 전에 넣는다.
```cpp
auto& raw=app_.getScene();
const auto frame=raw.worldMatrix(scene_.object("panel"));
if(!frame) return false;
const auto end=glm::vec3(*frame*glm::vec4(1,0,0,1));
if(!raw.setWorldPlacement(scene_.object("tray"),
    glm::translate(glm::mat4(1),end))) return false;
```
단위 박스가 아닌 panel 모델의 크기는 (2,1,.2)이므로 x=1은 오른쪽 끝의 중심이다. tray는 크기가 이미 Model에 반영되어 있고 지역 레이어가 없어서 위 T만 설정하면 된다. panel의 hinge를 X축으로 회전하게 바꿔 비교한다. 받침대의 Y축은 계속 월드 Y다. 실제 물리 안정화나 중력 계산을 하는 것이 아니라 방향을 지정한 기하 제약이다.

## 사용자가 확인할 결과

- [ ] panel의 기울기와 배율을 바꿔도 받침대가 눕거나 늘어나지 않는다.
- [ ] 끝점 위치는 panel의 최종 변환을 따른다.
- [ ] tray에 별도 지역 레이어가 있으면 setWorldPlacement 뒤 추가 변환됨을 설명한다.
