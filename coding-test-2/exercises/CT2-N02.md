# CT2-N02 · 비균등 배율과 경첩 기준점

경로: native · 권장 35분(실제 시험 시간 아님)

## 문제

폭 2, 높이 1, 깊이 0.5인 판을 만든다. 모델 지역점 (-0.5,0,0)을 월드 (1,0,0)에 고정하고 Y축으로 회전시킨다. 배율을 (3,1,0.25)로 바꿔도 경첩은 움직이면 안 된다. 회전 뒤 월드로 1만큼 밀 때와 회전 전에 지역으로 1만큼 밀 때를 비교한다.

## 상태·공간 설계

State.position은 도형 중심이 아니라 피벗의 월드 위치다. scale은 중심이 ±0.5인 단위 박스에 적용한다. 모델점 q에 M=T(anchor) R S T(-pivot)을 적용한다.

## 단계별 힌트

1. 피벗 q=pivot을 행렬식에 대입하면 T(-pivot)에서 0이 된다.
2. 월드 이동은 행렬 왼쪽, 물체 지역 이동은 오른쪽에 곱한다.

## 해설과 수정 코드

`State` 초기값을 바꾼다. 기존 모델 행렬 생성 코드가 이 정의를 이미 구현한다.
```cpp
glm::vec3 camera{6,4,8}, target{0}, position{1,0,0};
glm::vec3 scale{2,1,.5f}, pivot{-.5f,0,0};
```
수학을 직접 다시 쓰면 다음과 같다.
```cpp
const auto T=[](glm::vec3 p){return glm::translate(glm::mat4(1),p);};
const auto R=glm::rotate(glm::mat4(1),glm::radians(float(state.objectDegrees)),glm::vec3(0,1,0));
const auto M=T(state.position)*R*glm::scale(glm::mat4(1),state.scale)*T(-state.pivot);
const auto anchor=glm::vec3(M*glm::vec4(state.pivot,1));
const auto worldShift=T({1,0,0})*M;
const auto localShift=M*T({1,0,0});
```
`anchor`는 항상 (1,0,0)이다. localShift는 이동벡터도 R과 S를 거치므로 월드에서 길이 1이 아닐 수 있다. 배율 영향을 빼고 회전 방향으로만 이동하려면 T(anchor) R T(delta) S T(-pivot) 순서를 쓴다. 회전·이동의 목적에 따라 식이 달라진다.

## 사용자가 확인할 결과

- [ ] p를 눌러 자전시켜도 경첩점은 고정된다.
- [ ] 회전각 90도에서 월드 이동과 지역 이동의 방향 차이를 예측한다.
- [ ] 배율 0은 역행렬을 만들 수 없으므로 사용하지 않는다.
