# CT2-N04 · 반경이 바뀌는 공전과 궤도

경로: native · 권장 30분(실제 시험 시간 아님)

## 문제

광원 중심을 (1,0,-1)로 옮긴다. y/Y로 +/- 공전, z/Z로 반경 변경을 구현한다. 정지→반경 변경→역방향 재개 때 각도는 연속이어야 한다. 광원, 표시 물체, 원 궤도가 같은 중심과 반경을 써야 한다.

## 상태·공간 설계

상태 center, radius, height, phase, direction을 분리한다. 위치 하나를 저장해 따로 보정하지 않는다. 원 궤도 버퍼는 center/radius/height가 바뀔 때만 갱신한다.

## 단계별 힌트

1. angle=speed*누적 전체시간 식은 중간 정지에 적합하지 않다.
2. 이미 있는 point 람다에 center를 더하고 dirty 조건에도 center를 넣는다.

## 해설과 수정 코드

State에 `glm::vec3 orbitCenter{1,0,-1};`를 추가한다. 렌더 루프의 기존 point 람다를 바꾼다.
```cpp
const auto point=[&](double degrees) {
    const double a=degrees*pi/180;
    return state.orbitCenter+glm::vec3(state.radius*float(std::cos(a)),
        state.lightHeight,state.radius*float(std::sin(a)));
};
```
루프 앞에 `glm::vec3 previousCenter{1e9f};`를 추가한다. 궤도 갱신 if에 `previousCenter!=state.orbitCenter`를 OR로 넣고, 갱신 뒤 previousCenter를 저장한다. 기존 lightPosition uniform과 marker draw가 모두 point를 사용하므로 함께 이동한다. 기존 update의 lightDegrees += direction*45*dt는 보존한다. 반경 입력은 각도를 바꾸지 않는다.
```cpp
state.lightDegrees=std::remainder(
    state.lightDegrees+state.lightDirection*45*dt,360.0);
```
height는 중심에서의 Y 오프셋이다. 중심 Y까지 더하므로 월드 높이가 필요하면 그 차이를 계산한다.

## 사용자가 확인할 결과

- [ ] 정지 중 반경만 바꾸면 원의 같은 위상에 표시 물체가 놓인다.
- [ ] y를 두 번 누르면 정지, Y를 누르면 역방향이다.
- [ ] 원의 중심도 (1,0,-1)로 바뀐다.
