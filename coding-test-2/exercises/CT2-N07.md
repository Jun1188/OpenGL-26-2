# CT2-N07 · 새 형상과 재질을 코드로 등록하기

경로: standard · 권장 30분(실제 시험 시간 아님)

## 문제

Standard에 편평한 구를 추가한다. 중심은 (-2,1,0), 반지름은 0.6, 배율은 (1,0.5,1.5)다. 기존 박스 추가 명령을 억지로 구 명령처럼 사용하지 않는다. 재질의 Ks와 shininess를 각각 바꿔 하이라이트의 세기와 폭을 구별한다.

## 상태·공간 설계

초기 장면은 SceneSetup.cpp에서 작성한다. 구는 Model.meshes에 재질이 있고, 기본 다면체는 faces에 재질이 있다. 새 API addModel은 준비한 기하와 재질을 보존한다.

## 단계별 힌트

1. DiagramSystem::makeSphere로 Model을 만들고 meshes()를 순회한다.
2. 구의 radius와 worldPose.scale을 섞지 않는다.

## 해설과 수정 코드

SceneSetup.cpp의 `// @debug insert` 앞에 넣는다. 이 함수의 scene은 SceneAuthoring이다.
```cpp
auto sphere=graphics::DiagramSystem::makeSphere(.6f,24,16);
for(auto& mesh:sphere.meshes()) {
    mesh.material.color={.3f,.8f,.6f};
    mesh.material.ambientStrength=.25f;
    mesh.material.diffuseStrength=1.f;
    mesh.material.specularStrength=.8f;
    mesh.material.shininess=64.f;
}
graphics::Transform3D pose;
pose.basis={-2,1,0}; pose.scale={1,.5f,1.5f};
scene.addModel("ellipsoid",sphere,pose);
```
Ks는 0→0.8, shininess는 8→128로 각각 바꿔 비교한다. Ks는 정반사 계수, shininess는 지수다. Ks만 바꾸면 강도가 달라지고, 지수를 키우면 보통 하이라이트가 좁아진다. 재질 값과 광원 세기를 한꺼번에 바꾸지 않아야 원인을 비교할 수 있다. 미리 실행된 다른 셰이더 출력 모드가 있다면 F2로 합성 모드로 돌아온다.

## 사용자가 확인할 결과

- [ ] 찌그러진 구의 법선 출력이 연속적이다.
- [ ] Ks=0에서 정반사 출력은 검다.
- [ ] 지수만 바꿀 때 물체 실루엣은 같다.
