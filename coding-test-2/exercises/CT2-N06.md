# CT2-N06 · CPU→uniform→GLSL 한 번에 고치기

경로: native · 권장 35분(실제 시험 시간 아님)

## 문제

g로 최종 밝기를 1↔1.5배 바꾼다. 이어서 b키로 정반사 항만 켜고 끄는 specularEnabled uniform을 추가한다. 조명 전체 m 토글과 독립이어야 한다. 실수형/정수형 uniform의 CPU 호출을 구별한다.

## 상태·공간 설계

State bool→PRESS 토글→매 프레임 glUniform1i→GLSL bool→정반사 항 조건이다. gain은 glUniform1f. program을 사용한 후 전송한다.

## 단계별 힌트

1. gain은 기존 전체 예제가 있다. 새 값도 선언만 하고 안 쓰면 location=-1이 될 수 있다.
2. 조명 켜기와 재질 Ks=0은 관찰 효과가 다르다.

## 해설과 수정 코드

State에 `bool specularEnabled=true;`를 추가한다. key에 다음을 추가한다.
```cpp
if(key==GLFW_KEY_B) state.specularEnabled=!state.specularEnabled;
```
기존 uniform 구간에 넣는다.
```cpp
integer(shader,"specularEnabled",state.specularEnabled ? 1 : 0);
```
FragmentShader.glsl의 전역 선언과 specular 계산 다음에 넣는다.
```glsl
uniform bool specularEnabled;
// 기존 vec3 specular = ...; 바로 다음
if (!specularEnabled) specular = vec3(0.0);
```
gain 경로는 기존 scalar(shader,"gain",state.gain)와 fragmentColor=result*gain이다. 원본 GLSL을 바꾼 뒤 사용자가 프로젝트를 다시 빌드하여 출력 폴더의 셰이더 복사본도 바꾼다. 실행 중 핫 리로드는 구현하지 않았다. bool은 glUniform1i, float은 glUniform1f로 전송한다. 스스로 uniform 이름 하나를 틀리게 써서 CPU의 누락 오류가 무엇을 가리키는지 읽고 복구한다.

## 사용자가 확인할 결과

- [ ] b는 하이라이트만 바꾸고 확산은 남긴다.
- [ ] m으로 조명을 끄면 objectColor만 남는 기존 분기가 작동한다.
- [ ] 수정한 원본 GLSL과 실행 폴더의 파일이 같아야 한다.
