# CT2-N10 · 누르면 열리고 놓으면 돌아오는 판

경로: standard · 권장 35분(실제 시험 시간 아님)

## 문제

h를 누르는 동안 panel이 0→60도 열리고, 놓으면 0도로 복귀하게 한다. 속도는 40도/초다. 범위를 벗어나면 안 된다. 입력 반복과 무관해야 하고 Space 정지 때 멈춰야 한다.

## 상태·공간 설계

angle과 held를 독립적으로 저장한다. 입력은 held만 바꾸고 dt 갱신이 각도를 적분한다. hinge 레이어 하나의 소유자를 ExamController로 정한다. 기존 hinge.spin을 동시에 켜지 않는다.

## 단계별 힌트

1. PRESS/REPEAT와 RELEASE를 상태에 반영한다.
2. clamp(angle + sign*speed*dt,0,60) 후 setLayer한다.

## 해설과 수정 코드

ExamController.h의 State에 `float hatchAngle=0;`를 추가한다. move_ 옆에 `bool hatchHeld_=false;`를 둔다. initialize/reset과 onFocus(false)에서 hatchHeld_=false를 지정한다. onKey의 PRESS 필터 **앞**에 추가한다.
```cpp
if(key==GLFW_KEY_H) hatchHeld_=action!=GLFW_RELEASE;
```
ExamController::update에 추가한다.
```cpp
state_.hatchAngle=std::clamp(state_.hatchAngle+
    (hatchHeld_ ? 40.f : -40.f)*dt,0.f,60.f);
graphics::LayerSetup hatch;
hatch.pivot={-1,0,0}; hatch.rotationDegrees.z=state_.hatchAngle;
scene_.setLayer("panel","hinge",hatch);
```
Z축 회전은 판의 왼쪽 모서리를 중심으로 XY 평면에서 열린다. 기존 SceneSetup hinge의 spinDegreesPerSecond는 0으로 둔다. Console은 pause 시 dt=0을 전달하므로 이 컨트롤러도 멈춘다. 이 움직임은 정해진 속도의 복귀 애니메이션이다. 스프링·질량·토크를 계산한 물리 운동으로 설명하지 않는다.

## 사용자가 확인할 결과

- [ ] 60도에서 계속 눌러도 더 열리지 않는다.
- [ ] Space 정지 중에는 키를 놓아도 각도가 고정된다.
- [ ] 창을 벗어나면 held가 해제된다.
