# 실습 15: 입력과 중첩 모션

최신 구현의 소스 검토 결과다. 빌드·실행 테스트는 사용자 확인 필요다.
소스: ../openGL_3dAssign_15/Console.h, ../openGL_3dAssign_15/Console.cpp.

## 키별 동작

| 키 | 대상·진행 | 재입력 |
|---|---|---|
| T | 윗면 중점 Z축 회전 | 현재 각도에서 정지·재개 |
| F | 앞면 위쪽 모서리 X축, 0↔90도 열기·닫기 | 방향 반전, 끝점에서 자기 모션만 정지 |
| S | 왼쪽·오른쪽 면 각각 중점 X축 회전 | 두 면 함께 정지·재개 |
| B | 뒷면 중점 고정, 1↔0 축소·복원 | 방향 반전, 완전 축소 시 뒷면 숨김 |
| 1 | 최초 선택한 인접 두 면, 공통 수직 모서리로 360도 반복 | 현재 각도에서 정지·재개 |
| 2 | 최초 선택한 인접 두 면, 중앙 Y축으로 서로 반대 90도 교체 후 복귀 반복 | 현재 각도에서 정지·재개 |
| 4 | 옆면 네 개, 중앙 Y축 공전 | 현재 각도에서 정지·재개 |
| 5 | 위·아래·앞·뒤, 중앙 X축 공전 | 현재 각도에서 정지·재개 |
| Y | 전체 객체 로컬 Y축 자전 | 정지·재개 |
| P | 육면체/사각뿔 전환 | 면 모션 초기화, 전체 자전·깊이 설정 유지 |
| R | 육면체·초기 기울기·깊이 켜짐·전체 면 표시 | 전체 모션 초기화·정지 |
| H | 깊이 테스트 | 켜짐·꺼짐 |
| Q/Esc | 종료 | — |

회전은 45도/초다. 1은 8초 주기다. 2는 2초에 교체하고 다음 2초에 복귀한다.
1·2의 선택 쌍은 서로 독립이다. 정지·재개 중 유지하고 P/R 초기화 이후 첫 입력에서 다시 선택한다.
사각뿔에서는 Y 자전만 적용하며 육면체 면 키는 무시한다.

## 상태와 합성

motions_[Motion]은 initialized, running, progress, direction, pair, hinge를 보관한다.
입력은 지정 모션의 상태만 바꾼다. onUpdate는 모든 running 상태를 순회한다.
F/B가 완료되어도 다른 모션을 멈추지 않는다. 정지한 모션은 현재 변형을 유지한다.

applyFaceMotion은 여섯 면의 단위행렬을 만들고 다음 순서로 각 면에 해당하는 행렬만 합성한다.

T → F → S → B → 1 → 2 → 4 → 5 → 객체 Model

열벡터를 사용하므로 새 모션을 기존 행렬 왼쪽에 곱한다.
면 Model = 객체 Model × OrbitX × OrbitY × Swap × Hinge × Back × Side × Front × Top.
피벗과 축은 기준 형상 로컬 좌표다. 중첩 시 후속 공전은 앞서 변형된 면 전체를 이동시킨다.
그래서 단독 실행에서 고정되는 중점·모서리도 추가 공전 후에는 월드에서 움직일 수 있다.
매 프레임 기준 형상에서 계산하므로 이전 프레임의 면 행렬을 누적하지 않는다.

CPU 상태 → 면 localAnimationMatrix/visible → Renderer::draw의 uMVP → 정점 셰이더 → 화면.
행렬·표시 변경은 정점 버퍼 업로드를 유발하지 않는다.
initScene은 cube/pyramid 생성 → assignVertexColors 각각 호출 → push_entity 순서로 처리한다.
두 도형의 꼭짓점 색상은 GPU에서 보간된다.

## 사용자가 확인할 항목

1. S 단독 실행: 왼쪽·오른쪽 면이 함께 회전하고, 재입력으로 함께 정지·재개한다.
2. 1을 16초 이상 실행: 두 번 이상 회전하고 자동 종료하지 않는다.
3. 2를 8초 이상 실행: 교체·복귀가 두 번 이상 이어진다. 중간에서 정지·재개해도 선택 쌍이 유지된다.
4. T/S/1/2/4/5/Y를 순차 입력: 모두 동시에 진행하며 키 하나로 멈춰도 나머지는 계속 움직인다.
5. F/B를 추가하고 완료·반전: 다른 회전은 계속 진행한다. B 복원 시 뒷면이 다시 표시된다.
6. P 전환: 면 동작 초기화와 전체 자전 유지. R 입력: 전체 초기화.
7. 색상 보간, 깊이 전환, 창 크기 변경·최소화·복원·종료를 확인한다.
