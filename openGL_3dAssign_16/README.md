# 실습 16

openGL_assign_16.slnx를 Visual Studio에서 열고 Debug/Release x64로 빌드한다. C++17·v145를 사용한다. 빌드와 실행 테스트는 사용자가 수행한다.

main.cpp는 콜백을 등록하고 Console이 해당 실습의 입력·상태·장면을 관리한다. framework 폴더가 모든 외부 라이브러리를 포함한다. 프로젝트 폴더 전체를 복사하여 단독 제출할 수 있다. DLL은 실행 폴더의 framework/dependencies로 배치된다.

상세 키와 예상 결과는 저장소 docs/practice-14-19/README.md와 USER_CHECKS.md에 있다. 프레임워크 공통 응용 패턴은 framework/docs/APPLICATION_PATTERNS.md에 있다. 단독 배포 시 Console.cpp의 시작 안내와 onKey를 함께 참고한다.

### 16

15의 육면체 키와 H/P/Y/R/Q를 유지한다. 6~9를 누르면 사각뿔을 선택한다. 6~9는 같은 네 옆면을 제어하므로 서로 다른 사각뿔 모드를 고르면 닫힌 자세에서 새 모드를 시작한다. 바닥은 고정한다.

- 6: 모든 옆면을 아래 모서리에서 회전하여 아래 공통 꼭짓점에서 만나게 한다. 같은 키는 열기/닫기 방향을 바꾼다.
- 7: 앞/오른쪽/뒤/왼쪽 순서로 한 면씩 1초 열고 1초 닫는다. 같은 키는 정지/재개다.
- 8: 앞/뒤 면이 위 꼭짓점의 Y축을 중심으로 반대 방향 180° 이동하여 자리를 바꾼다. 도중에는 정지/재개, 끝난 뒤에는 복귀한다.
- 9: 위 꼭짓점을 고정하고 네 옆면을 바깥쪽으로 45° 연다. 같은 키는 방향을 바꾼다.

높이 0.8·반폭 0.4다. 6의 실제 힌지 회전은 안쪽 방향 126.870°, 7의 바깥 평면 펼침은 116.565°다. 문서의 180°·90°를 목표 자세로 해석했다. 꼭짓점을 직접 밀거나 면의 크기를 바꾸지 않는다. 6의 이동 도중에는 바닥과의 교차를 허용한다. 충돌 검사는 실습 요구 범위가 아니다.


사용자 확인: 빌드, 조작 키, 상대경로 배포, 창 크기·최소화·포커스 이탈·종료를 직접 확인한다.
