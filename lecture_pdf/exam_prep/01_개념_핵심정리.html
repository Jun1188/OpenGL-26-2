01. 개념 정의 · 파이프라인 · 알고리즘 수행 과정 총정리

개념 문항(30~40%)의 최빈출 유형인 "파이프라인 단계 서술", "각 알고리즘의 수행 과정(Step-by-step)", "핵심 용어 정의·비교"에 바로 답할 수 있도록 정리했습니다.

시험 개념 서술 요령

과정 서술 문제가 나오면 ① 목적(한 줄 정의) → ② 입력/기준 설정 → ③ 단계별 처리 순서(화살표 흐름) → ④ 최종 출력의 4박자로 적으면 만점 답안이 됩니다.

0-2. 클리핑 알고리즘 4종 단계별 수행 과정

① Liang-Barsky 선 클리핑 과정 ★ (최빈출)

  1. 선분을 매개변수식 P(u) = P1 + (P2−P1)u (0 ≤ u ≤ 1)로 표현.
  2. 윈도우(2D: 4경계, 3D: 6경계) 부등식을 u · pk ≤ qk 형태로 정리.
  3. 평행 검사(pk = 0): 만약 qk < 0이면 경계 외부에 평행하므로 즉시 기각(Reject).
  4. 진입/진출 경계 교차 매개변수 계산(pk ≠ 0): rk = qk / pk 계산.
    • pk < 0 (밖→안 진입): ustart = max(0, 모든 진입 rk)
    • pk > 0 (안→밖 진출): uend = min(1, 모든 진출 rk)
  5. 유효 구간 판정: ustart > uend이면 선분이 윈도우 밖이므로 기각; ustart ≤ uend이면 P(ustart), P(uend)로 새 끝점 확정.

② Cohen-Sutherland 선 클리핑 과정

  1. 공간을 윈도우 기준 9개 영역(2D: 4비트 TBRL) 또는 27개 영역(3D: 6비트 FBABRL)으로 나누고 양 끝점에 영역코드 부여.
  2. 완전 내부 검사: 두 코드 모두 0이면 그대로 그림(채택).
  3. 완전 외부 검사: 두 코드의 비트 AND ≠ 0이면 같은 바깥 반공간에 있으므로 즉시 기각.
  4. 교차 절단 반복: 위 두 경우가 아니면(한쪽만 0이거나, 둘 다 ≠0이고 AND=0), 외부 끝점의 비트가 1인 경계선과 교차점을 구해 외부 구간을 잘라내고 새 끝점 코드를 다시 부여해 2번부터 반복.

③ Sutherland-Hodgman 다각형 클리핑 과정

  1. 입력 다각형의 정점 배열을 윈도우의 한쪽 무한 경계선(예: 좌→상→우→하 순서)에 대해 하나씩 순차적으로 클리핑(파이프라인 구조).
  2. 각 경계마다 인접 정점 쌍 (S → E)을 따라가며 4가지 규칙으로 출력 정점 리스트 구성:
    • 외→내: 교점 I, 끝점 E 둘 다 저장
    • 내→내: 끝점 E만 저장
    • 내→외: 교점 I만 저장
    • 외→외: 저장 안 함
  3. 한 경계의 출력 정점 리스트를 다음 경계의 입력으로 넘겨 4개 경계를 모두 거치면 닫힌 채워진 다각형 완성.

④ Weiler-Atherton 오목 다각형 클리핑 과정

  1. 오목 다각형이 클리핑 후 여러 개의 분리된 다각형 조각으로 나뉠 때 사용.
  2. 다각형 정점과 윈도우 경계의 교점(진입점·진출점)을 구해 연결 리스트 구성.
  3. 진입점(외→내)에서 시작해 다각형 경계를 시계방향으로 추적하다가, 진출점(내→외)을 만나면 클리핑 윈도우 경계를 시계방향으로 따라 원래 진입점으로 복귀하여 하나의 닫힌 다각형 분리 완성(남은 미방문 진입점에 반복).

0-3. 은면 제거 알고리즘 3종 단계별 수행 과정 ★

① 뒷면 제거 (Back-face Removal)

  1. 은면 제거 첫 단계에서 다면체의 보이지 않는 뒷면(약 50%)을 면 단위로 사전 제거(객체 공간법).
  2. 각 다각형 면의 바깥쪽 법선 벡터 N = (A, B, C) 계산.
  3. 시선 방향 벡터 V와의 내적 V·N 부호 검사 (시점 +z, 시선 −z일 때 V·N = CVz).
  4. V·N < 0 (C > 0)이면 앞면이므로 렌더링 유지, V·N > 0 (C < 0)이면 뒷면이므로 제거.

② Z-Buffer (깊이 버퍼) 과정

  1. 버퍼 2개 초기화: 모든 픽셀 (x,y)에 대해 Depth(x,y) = −∞(최소값), Frame(x,y) = 배경색 설정(시선 −z 기준).
  2. 각 다각형 면이 투영되는 모든 픽셀 (x,y)에 대해 평면 방정식(및 증분식 z' = z − A/C)으로 깊이값 z 계산.
  3. 깊이 비교: z > Depth(x,y)(더 시점에 가까움)이면 Depth(x,y) = z로 갱신하고 Frame(x,y) = 면의 색상으로 덮어씀.
  4. 모든 다각형 처리가 끝나면 프레임버퍼 출력(면의 처리 순서와 무관!).

③ 깊이 정렬 (Painter's) 과정

  1. 모든 다각형 면을 시점(투영면)으로부터의 깊이(|z|)에 따라 가장 먼 면부터 가까운 면 순으로 정렬.
  2. 인접한 면 S1(먼 후보), S2의 z 영역이 겹치지 않으면 S1부터 즉시 그림.
  3. z 영역이 겹치면 4가지 비가림 검사 수행: ① x/y 화면 영역 비겹침 ② S1 모든 정점이 S2 평면 뒤쪽(<0) ③ S2 모든 정점이 S1 평면 앞쪽(>0). 하나라도 참이면 S1이 S2를 가리지 않으므로 S1 확정.
  4. 모두 거짓이면 S1과 S2의 순서를 교체해 재검사하며, 관통·순환 중첩으로 해결 불가 시 면을 분할한 뒤 그린다.

0-4. 스플라인 & 베지어 곡선 구성 과정 요약

  • 3차 매개변수 스플라인 공통 구조: P(u) = au3+bu2+cu+d = U · C = U · Mspline · Mgeom (0 ≤ u ≤ 1). 4개의 경계조건(Mgeom)을 설정하고 그 역행렬로 특성행렬 Mspline을 도출하여 다항식 계수 C = [a,b,c,d]T를 구함.
  • 허마이트 → 카디널 → 캣멀롬 발전 흐름:
    • 허마이트: 사용자가 양 끝점(pk, pk+1)뿐 아니라 양 끝 접선 벡터(Dpk, Dpk+1)를 직접 입력해야 함.
    • 카디널: 접선을 직접 입력하는 번거로움을 없애기 위해 이웃 제어점(pk−1, pk+2)의 차이와 장력 t로부터 접선 ½(1−t)(pk+1−pk−1)을 자동 계산.
    • 캣멀롬: 카디널에서 장력 t = 0 (계수 s = ½)으로 고정한 표준 균일 보간 곡선.
  • 베지어(Bézier) 생성 과정 (de Casteljau & 번스타인): n+1개의 제어점 사이를 비율 t : (1−t)로 반복 선형 보간하여 최종 1개의 곡선 점 P(t)를 얻거나, 각 제어점에 n차 번스타인 배합함수를 곱해 합산.

2. 4강: 윈도우 · 뷰포트 · 클리핑 개념 계산 기반

  • 윈도우(Window): 세계 좌표에서 선택된 영역("무엇을 보여줄지") vs 뷰포트(Viewport): 출력 장치 내 표시 영역("어디에 보여줄지").
  • 3대 효과: Zooming(윈도우 크기 축소→확대, 확장→축소), Panning(윈도우 평행이동), Multi viewport(하나의 장면을 여러 뷰포트에 동시 출력).
  • 월드 좌표 클리핑 vs 뷰포트 클리핑: 클리핑 시점만 다르고 최종 화면 결과는 동일.

3. 6강: 3차원 그래픽스 처리과정 & 기하변환 본 시험범위

  • 모델링 7가지 기법 (슬라이드 4): ① 다각형 표면 모델링 ② 매개변수 곡면 모델링 ③ 와이어프레임 ④ 솔리드 모델링 ⑤ 스위핑 ⑥ 프랙털 기하학 ⑦ 입자 시스템.
  • 렌더링 3가지 세부 과정 (슬라이드 6): ① 은면 제거(Hidden Surface Removal) ② 쉐이딩(Shading) ③ 텍스쳐 매핑(Texture Mapping).
  • 3D 회전 3단계 난이도 구분: ① 좌표축(x,y,z) 회전 ② 좌표축에 평행한 직선 회전(3행렬: T·R·T−1) ③ 일반 직선 회전(7행렬: 원점 이동 → Rx, Ry로 z축 정렬 → Rz(θ) → 역회전 → 역이동).

등축 투영직각 투영 중 세 축이 투영면과 동일 각도를 이뤄 3면이 동시 노출(축간 120°).아이소메트릭 게임, 부품 조립도
경사 투영투영선이 투영면과 수직이 아닌 각도 α 형성, 투영 평면 내 각도 φ 사용.Cavalier: α=45°(tanα=1, 깊이 1배)

원근 투영
(원근감 표현)		1·2·3점 투시모든 투영선이 투영 중심점(COP/시점)으로 수렴. 투영 크기가 거리에 반비례, 평행선이 소실점(Vanishing Point)에서 만남.조감도, 3D 게임·시뮬레이션
  • 뷰잉 좌표계 3요소: VRP(카메라 기준점/원점), VPN(뷰 평면 법선 → zv축), VUP(화면 위쪽 → yv축 방향, xv축은 자동 외적 결정).
  • 뷰볼륨(View Volume) 정규화의 핵심 의의: 평행 뷰볼륨이나 원근 프러스텀을 모두 표준 정육면체(OpenGL NDC: [−1, 1]3)로 변환하면 ① 클리핑을 단순 경계(±1) 비교로 처리 가능하고 ② 원근 투영도 직각투영과 동일한 방식으로 처리 가능하며 ③ 장치좌표계 변환이 일관됨.

5. 8강: 3차원 객체 모델링 (메쉬 · 평면 · 스플라인 · 베지어) 본 시험범위

  • 삼각 메쉬 vs 사각 메쉬: 일직선이 아닌 3점은 항상 단일 평면을 결정하지만, 사각형의 4점은 비평면일 수 있어 렌더링 시 2개의 삼각형으로 분할 처리. 가속기 성능 = 초당 렌더링 삼각형 개수.
  • 스위핑 & CSG: 스위핑 = 2D 단면의 병진/회전 이동으로 3D 생성; CSG = 기본 입체들의 집합 연산(∪, ∩, −) 반복 조립.
  • 평면 방정식 Ax+By+Cz+D=0: 법선 (A,B,C), <0 안쪽, =0 평면 위, >0 바깥쪽. 클리핑·은면제거·충돌 판정에 핵심 활용.
곡선 종류보간/근사입력 조건핵심 특징
Hermite보간 (통과 O)2개 끝점 + 2개 끝점 접선양 끝점과 접선 직접 지정, 국부 제어 가능
Cardinal ★보간 (통과 O)연속 4개 제어점 + 장력 t이웃 두 점으로 접선 자동 계산, 장력 t로 곡선 팽팽함/느슨함 조절

Bézier ★근사 (시작·끝만 통과)n+1개 제어점 (→ n차 다항식)번스타인 배합함수 사용, Convex Hull 내부 존재, 전역 제어(제어점 1개 이동 시 전체 영향)

6. 9강: 은면 제거 & 컬러 모델 본 시험범위

비교 항목객체 공간법 (뒷면 제거, 깊이 정렬)이미지 공간법 (Z-Buffer)
비교 단위3D 공간의 객체/다각형 면 상호 위치 관계투영면의 각 픽셀별 투영선 최단 관통 면
계산 복잡도모든 면 수의 제곱(O(n2))에 비례픽셀 해상도 × 객체 수에 비례
특징·한계정밀도 높음, 객체 수 적을 때 유리; 복잡한 겹침 시 면 분할 필요구현 단순, 임의 순서 렌더링 가능; 해상도 의존 & 대용량 버퍼 메모리 필요
  • 빛의 3속성: 색상(Hue, 파장), 밝기(Brightness), 채도(Saturation, 순수도; 낮으면 회색). 가시광선: 빨강(4.3×1014Hz) ~ 보라(7.5×1014Hz).
  • 보색 쌍 (가산 합 = 백색): Red ↔ Cyan, Green ↔ Magenta, Blue ↔ Yellow.
  • RGB(가산, 모니터, 원점=검정) vs CMY(감산, 프린터, 원점=흰색, 인쇄는 CMYK) vs HSV(육각뿔, 인간 직관 근접: Tints=+흰색, Shades=+검정, Tones=검정+흰색).

7. 10강: 절차적 그래픽스(프랙탈) & 애니메이션 본 시험범위

  • 프랙탈 3대 특징: ① 비정수적 차원 ② 자기복제(Self-similarity) ③ 무한 순환 반복(확대 시 계속 새 디테일).
  • 프랙탈 생성 기법 3종: ① IFS(Barnsley 고사리) ② 생성 문법(Dragon curve: 1~4세대 선분 2→4→8→16) ③ 중점 변위법(정규분포 난수 변위, 산의 지형).
  • 애니메이션: 잔상 지속시간 이내 간격 유지(영화 24fps, NTSC 30fps). 플립북(전 프레임 저장) / 셀(배경·전경 분리 합성) / 키프레임(트위닝·선형보간) / 모핑(대응점 지정 변형) / FK(루트→말단 누진 계산) vs IK(말단 Effector 지정 → 관절 역산).

8. 강의 PDF 원문 오타·표기 불일치 주의점 6선

슬라이드 원문 그대로 외우면 위험한 지점들
  1. 4강 p.15 (Liang-Barsky pk=0): 아래 결론 줄의 qk < 0은 오타이며, 올바른 조건은 qk < 0 기각 / qk ≥ 0 유지(타 경계 검사).
  2. 4강 p.24 (Weiler-Atherton): 내→외 진출 시 텍스트('폴리곤 경계')와 달리 그림처럼 클리핑 윈도우 경계를 시계방향으로 추적함.
  3. 7강 p.5 vs p.6 (경사 투영 α): 수식 tan α = z/L과 행렬 cot α는 모두 p.6 정의("투영선과 투영면이 이루는 각 α") 기준.
  4. 8강 p.16 (카디널 장력 t): 수식 ½(1−t)에서는 t=0이 Catmull-Rom(s=½), t=1이 접선 0. 계산은 무조건 s = (1−t)/2로 수행!
  5. 8강 p.20 (베지어 차수 그림): 그림 제어점 수가 1개씩 많게 그려져 있음. 공식 정의는 p.19 기준 제어점 n+1개 = n차 베지어(4점 → 3차).
  6. 10강 p.10 (시어핀스키 차원): ln 3 / ln 2 = 1.58496… (슬라이드 1.6... 표기). 시험에는 ln 3 / ln 2 ≈ 1.585 (약 1.6) 병기 권장.
