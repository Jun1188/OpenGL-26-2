모든 3D 어파인 변환(이동·회전·신축·반사·밀림)은 마지막 행이 [0, 0, 0, 1]입니다. 좌상단 3×3 선형부를 A, 우측 3×1 이동 벡터를 t로 쓰면:

② 기준점 p0 샌드위치 공식:   T(p0) · A · T(−p0) = Ip00T1 A00T1 I−p00T1 = Ap0 − Ap00T1
③ 어파인 역행렬 & 회전 역행렬:   At0T1−1 = A−1−A−1t0T1,    특히 회전은 직교행렬이므로 R(−θ) = R(θ)−1 = R(θ)T!

→ 3×3 부분 A = Rx(90°) (즉 (x,y,z)→(x,−z,y)). Ap0 = (2, −3, −1)T. 따라서 4열 이동 성분 = p0 − Ap0 = (2−2, −1−(−3), 3−(−1))T = (0, 2, 4)T! 행렬 3개를 일일이 곱할 필요가 없습니다.

2-2. 최우선 타겟 ★: Liang-Barsky 알고리즘 수식 유도 & 사물 단위 클리핑 Full-step

Liang-Barsky 부등식 완전 유도 (왜 pk < 0이 진입이고 pk > 0이 진출인가?)

선분 x(u) = x1 + dx·u, y(u) = y1 + dy·u (0 ≤ u ≤ 1, dx = x2−x1, dy = y2−y1)가 윈도우 내부에 있을 필요충분조건은:

  • 왼쪽: xmin ≤ x1 + dx·u  ⇔  (−dx)u ≤ x1 − xmin  (p1 = −dx, q1 = x1 − xmin)
  • 오른쪽: x1 + dx·u ≤ xmax  ⇔  (+dx)u ≤ xmax − x1  (p2 = +dx, q2 = xmax − x1)
  • 아래쪽: ymin ≤ y1 + dy·u  ⇔  (−dy)u ≤ y1 − ymin  (p3 = −dy, q3 = y1 − ymin)
  • 위쪽: y1 + dy·u ≤ ymax  ⇔  (+dy)u ≤ ymax − y1  (p4 = +dy, q4 = ymax − y1)

부등식 pk u ≤ qk를 양변 pk로 나눌 때:
• pk < 0이면 부등호 방향이 뒤집혀 u ≥ qk/pk (하한선 = 밖→안 진입!) → 따라서 ustart = max(0, 모든 진입 qk/pk).
• pk > 0이면 부등호 방향이 그대로 u ≤ qk/pk (상한선 = 안→밖 진출!) → 따라서 uend = min(1, 모든 진출 qk/pk).

★ [실전 사물 클리핑 예제] 삼각형 와이어프레임 객체 ΔABC (A(0,4), B(6,8), C(6,4))를 윈도우 [2, 8] × [2, 6]에 Liang-Barsky로 클리핑하시오.

사물(와이어프레임 객체) 클리핑 문제는 객체를 구성하는 모든 모서리 선분(AB, BC, CA)에 대해 각각 Liang-Barsky 테이블을 작성해 클리핑된 선분 집합을 구합니다.

  1. 변 AB: (0, 4) → (6, 8)  [dx = 6, dy = 4]
    • k=1(좌 2): p1=−6(<0 진입), q1=0−2=−2 → r1 = 1/3
    • k=2(우 8): p2=+6(>0 진출), q2=8−0=8 → r2 = 4/3
    • k=3(하 2): p3=−4(<0 진입), q3=4−2=2 → r3 = −1/2
    • k=4(상 6): p4=+4(>0 진출), q4=6−4=2 → r4 = 1/2
    • ⇒ ustart = max(0, 1/3, −1/2) = 1/3,  uend = min(1, 4/3, 1/2) = 1/2.
      ⇒ 클리핑된 변 A'B': (0+6·⅓, 4+4·⅓) = (2, 16/3) ~ (0+6·½, 4+4·½) = (3, 6).
  2. 변 BC: (6, 8) → (6, 4)  [dx = 0 (수직 평행선!), dy = −4]
    • k=1,2(좌·우): p1=p2=0, q1=6−2=4 ≥ 0, q2=8−6=2 ≥ 0 → 윈도우 내부 평행선 통과!
    • k=3(하 2): p3=+4(>0 진출), q3=8−2=6 → r3 = 3/2
    • k=4(상 6): p4=−4(<0 진입), q4=6−8=−2 → r4 = 1/2
    • ⇒ ustart = max(0, 1/2) = 1/2,  uend = min(1, 3/2) = 1.
      ⇒ 클리핑된 변 B''C: (6, 6) ~ (6, 4).
  3. 변 CA: (6, 4) → (0, 4)  [dx = −6, dy = 0 (수평 평행선!)]
    • k=3,4(하·상): p3=p4=0, q3=2 ≥ 0, q4=2 ≥ 0 → 내부 평행 통과!
    • k=1(좌 2): p1=+6(>0 진출), q1=6−2=4 → r1 = 2/3
    • k=2(우 8): p2=−6(<0 진입), q2=8−6=2 → r2 = −1/3
    • ⇒ ustart = 0,  uend = 2/3 → 클리핑된 변 CA'': (6, 4) ~ (2, 4).

(참고: PDF 4강 p.18~19 예제 정답 — 윈도우 [5,10]×[5,10]에서 (3,8)→(12,2)는 u=[2/9, 1/2] ⇒ (5, 20/3)~(7.5, 5); (8,9)→(2,6)은 u=[0, 1/2] ⇒ (8, 9)~(5, 7.5) / PDF p.12 CS 예제 [−10,10]2에서 (−15,−15)→(12,8)은 (−210/23, −10)~(10, 170/27).)

2-3. Sutherland-Hodgman 채워진 다각형(사물) 클리핑 Full-step 정점 추적

★ [수치 정점 추적 예제] 채워진 삼각형 V0(−2, 2), V1(4, 8), V2(4, 2)를 윈도우 [0, 6] × [0, 6]에 클리핑하시오.

속이 찬 사물(다각형)일 때는 선분만 자르면 모서리 부분이 뚫리므로 Sutherland-Hodgman으로 정점 리스트를 순차 갱신합니다:

  1. 1단계 — 왼쪽 경계 (x ≥ 0): 입력 [(-2,2), (4,8), (4,2)]
    • (−2,2)[외] → (4,8)[내]: 외→내 ⇒ 교점 (0, 4)와 끝점 (4, 8) 저장
    • (4,8)[내] → (4,2)[내]: 내→내 ⇒ 끝점 (4, 2) 저장
    • (4,2)[내] → (−2,2)[외]: 내→외 ⇒ 교점 (0, 2)만 저장
    • 1단계 출력(4각형): [(0,4), (4,8), (4,2), (0,2)]
  2. 2단계 — 위쪽 경계 (y ≤ 6): 입력 [(0,4), (4,8), (4,2), (0,2)]
    • (0,4)[내] → (4,8)[외]: 내→외 ⇒ 교점 (2, 6) 저장
    • (4,8)[외] → (4,2)[내]: 외→내 ⇒ 교점 (4, 6)과 끝점 (4, 2) 저장
    • (4,2)[내] → (0,2)[내]: 내→내 ⇒ (0, 2) 저장
    • (0,2)[내] → (0,4)[내]: 내→내 ⇒ (0, 4) 저장
    • 2단계 출력(5각형): [(2,6), (4,6), (4,2), (0,2), (0,4)]
  3. 3·4단계 — 오른쪽(x ≤ 6) & 아래쪽(y ≥ 0): 5개 정점 모두 내부이므로 그대로 유지!
    ⇒ 최종 클리핑된 닫힌 5각형: (0, 2) → (0, 4) → (2, 6) → (4, 6) → (4, 2) (윈도우 모서리 꼭짓점이 아닌 경계 변을 따라 닫힌 채워진 오각형 완성!).

5-2. 허마이트(Hermite) 스플라인 — 4원 연립방정식 직접 유도 (슬라이드 15 빈칸)

[슬라이드 15 빈칸] 왜 MH가 [2,−2,1,1 / −3,3,−2,−1 / 0,0,1,0 / 1,0,0,0] 인가?

P(u) = au3 + bu2 + cu + d,  P'(u) = 3au2 + 2bu + c 에서:

  • ① P(0) = d = pk  ⇒  4행 = [1, 0, 0, 0]
  • ② P'(0) = c = Dpk  ⇒  3행 = [0, 0, 1, 0]
  • ③ P(1) = a + b + c + d = pk+1  ⇒  a + b = pk+1 − pk − Dpk
  • ④ P'(1) = 3a + 2b + c = Dpk+1  ⇒  3a + 2b = Dpk+1 − Dpk
  • ④ − 2×③: a = 2pk − 2pk+1 + Dpk + Dpk+1  ⇒  1행 = [2, −2, 1, 1]
  • ③ − a: b = −3pk + 3pk+1 − 2Dpk − Dpk+1  ⇒  2행 = [−3, 3, −2, −1]!

6-4. 컬러 변환 · 프랙탈 · 키프레임 보간 · 다관절 FK 요약 공식

  • RGB ↔ CMY / CMYK: C = 1−R, M = 1−G, Y = 1−B. (참고: 인쇄 CMYK 변환 시 K = min(C, M, Y)를 뽑아 검정 잉크로 대체).
  • 프랙탈 차원 응용: D = ln N / ln(1/S). (예: 멩거 스펀지 — 정육면체를 3×3×3=27등분 후 중심과 각 면 중앙 7개를 빼서 N=20개 유지 → S=1/3, D = ln 20 / ln 3 ≈ 2.727).
  • 키프레임/모핑 선형 보간: s = (f − f0)/(f1 − f0),  P(s) = (1−s)P0 + sP1.
  • 다관절 FK 최종 행렬: 루트 이동 T0 → 관절1 회전 R1 → 뼈대1 길이 이동 T(L1, 0, 0) → 관절2 회전 R2 일 때 말단 월드 변환 행렬은 Mend = T0 · R1 · T(L1,0,0) · R2!
