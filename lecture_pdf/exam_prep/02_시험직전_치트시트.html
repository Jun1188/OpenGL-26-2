1. 최종 단일 행렬을 15초 만에 구하는 블록 곱셈 공식 ★

① 어파인 2개 곱:   A2t20T1 A1t10T1 = A2A1A2t1 + t20T1
② 기준점 p0 샌드위치 공식 (회전·신축·반사 만능!):   T(p0) · A · T(−p0) = A(I − A)p00T1 = Ap0 − Ap00T1

해석: 임의의 점 p0 기준 회전/신축의 최종 단일 행렬은 좌상단 3×3에 A를 그대로 쓰고, 4열 이동 성분만 p0 − Ap0를 적으면 행렬 3개 곱셈이 즉시 끝납니다!

5. 은면 제거 · 평면 · 컬러 · 프랙탈 · 보간 1줄 공식

• 평면: N=(A,B,C)=(P2−P1)×(P3−P1), D=−N·P1  |  거리 d = |Ax1+By1+Cz1+D| / √(A2+B2+C2)
• 뒷면 제거: 시선 V = P − Eye 에 대해 V·N < 0 앞면, > 0 뒷면 (시선 −z 평행이면 C > 0 앞면, C < 0 뒷면)
• Z-버퍼 깊이: z(x,y) = −(Ax+By+D)/C  |  우측 증분 z(x+1,y) = z − A/C  |  스캔라인 증분 z(x,y−1) = z + B/C
• 깊이 정렬 유지 조건(S1 먼저): S1 모든 정점이 S2 식 < 0 (뒤) 또는 S2 모든 정점이 S1 식 > 0 (앞)
• 프랙탈 차원: D = ln N / ln(1/S)  |  선형 보간: P(s) = (1−s)P0 + sP1  |  CMY: (1−R, 1−G, 1−B)

6. 시험장 빈출 O/X 함정 20선

#함정 진술답핵심 근거
1이동 변환은 선형 변환에 속한다.X어파인 변환에는 속하지만 원점을 보존하지 않아 선형 변환 아님.
2T(P0)·A·T(−P0)의 최종 4열 이동 벡터는 P0 − AP0이다.O블록 곱셈 시 (I − A)P0가 되어 기준점 P0가 불변점으로 유지됨.
3오른손 좌표계 Ry(θ)의 1행 3열은 −sin θ이다.XRy만 1행 3열이 +sin θ, 3행 1열이 −sin θ!
4Liang-Barsky에서 pk = 0이고 qk ≥ 0이면 즉시 선분을 기각한다.Xqk < 0일 때만 외부 평행으로 기각; qk ≥ 0이면 내부 평행이므로 나머지 경계 계속 검사.
5Liang-Barsky에서 pk < 0은 밖→안 진입, pk > 0은 안→밖 진출 경계다.O진입은 u1 = max(0, …), 진출은 u2 = min(1, …).
6Sutherland-Hodgman에서 내부→외부 이동 시 교점과 끝점을 모두 저장한다.X내→외는 교점만 저장; 외→내일 때 교점+끝점 둘 다 저장.
7Cabinet 투영은 깊이 길이를 1/2배로 축소해 투영한다.Oα=63.4°(tanα=2, cotα=0.5). 1배 유지는 Cavalier(α=45°).
8뷰 변환 행렬 Mview에서 기저벡터 u, v, n은 1·2·3열에 세로로 배치된다.X월드→뷰 회전은 직교 역행렬(전치)이므로 1·2·3행(가로)에 배치됨!
9원근 정규화 행렬 곱셈만으로 NDC 좌표가 완성되며 별도 나눗셈은 불필요하다.X4번째 동차 성분 h (= −z 또는 1−z/d)로 나누는 원근 나눗셈이 필수!
10카디널 스플라인은 4개의 제어점 p0, p1, p2, p3을 한 구간 식 하나로 모두 통과한다.X단일 구간 곡선은 가운데 두 점 p1 ~ p2 사이만 연결하며 p0, p3은 접선 계산에만 사용됨!
11캣멀롬(Catmull-Rom) 스플라인은 카디널 스플라인에서 s = 1/2 (t = 0)인 특수 경우다.OP'(0) = ½(pk+1−pk−1), P'(1) = ½(pk+2−pk).
125개의 제어점으로 정의되는 베지어 곡선은 5차 다항식이다.X차수 = 제어점 수 − 1 이므로 4차 다항식!
13베지어 배합함수들의 합은 임의의 t ∈ [0, 1]에서 항상 1이다.O이항정리에 의해 ∑ Bk,n(t) = ((1−t)+t)n = 1n = 1 (Convex Hull 성질의 근거).
143차 베지어 곡선의 시작점 접선 벡터 P'(0)은 3(P1 − P0)이다.O끝점 접선 벡터 P'(1)은 3(P3 − P2).
15뒷면 제거만으로 오목 다면체나 여러 물체 간의 가림 현상을 완전히 해결할 수 있다.X앞면끼리 서로 가리는 것은 제거 못 하므로 Z-버퍼나 깊이 정렬이 추가로 필요.
16Z-버퍼 알고리즘은 다각형을 반드시 먼 순서대로 정렬한 뒤에 처리해야 한다.X픽셀마다 깊이를 비교·갱신하므로 다각형 입력 순서와 무관하게 동일 결과 생성!
17깊이 정렬(Painter's)에서 두 면이 서로 관통하면 순서 교체만으로 해결되지 않아 면 분할이 필요하다.O순환 중첩(Cyclic overlap)과 상호 관통 시 면 분할 후 재검사 수행.
18HSV 모델에서 V = 0이면 H와 S 값에 관계없이 항상 검정색이다.O명도 V=0은 육각뿔 꼭짓점(Black).
19중점 변위법은 프랙탈 생성 기법 중 하나로 산의 표면 모델링에 적합하다.O변의 중점을 정규분포 난수로 변위시켜 반복 세분화.
20역운동학(IK)은 루트 관절 각도를 입력해 말단 위치를 순차 계산하는 방식이다.X그것은 운동학(FK); IK는 말단 Effector 위치로부터 중간 관절 각도를 역산.
