# 실습 26: 사용자 확인

이 폴더 전체를 저장소 밖의 별도 경로로 **복사**한 뒤 `.sln`의 Debug/Release x64를 사용한다. 원본을 이동·삭제할 필요는 없다. 폴더 내부 framework에 소스·헤더·GLM/GLFW·런타임 DLL·셰이더·라이선스가 포함돼 있다. 상위/형제 framework를 참조하지 않는다. Visual Studio C++ 도구·Windows SDK·OpenGL 3.3 지원 드라이버는 시스템 요구다.

빌드·테스트·앱 실행은 에이전트가 수행하지 않았다. 아래 확인은 사용자가 수행한다.

1. **시작/n**: 육면체·사각뿔에 조명 적용. 예상: 두 형상을 생성하고 하나만 표시; 같은 회전 상태 유지.
2. **시작**: 객체 앞쪽 광원과 작은 도형 표시. 예상: 초기 광원 (0,0,3), .25 크기 비조명 표시.
3. **n**: 육면체/사각뿔 전환. 예상: shape_ 전환, 객체 위치·회전 유지.
4. **m**: 조명 켜기/끄기. 예상: 조명 계산을 켜거나 끄며 표시 객체는 unlit 유지.
5. **y**: 객체 중심 Y축 자전. 예상: 현재 위치를 유지하고 Y 회전, 재입력으로 정지.
6. **r/R**: 광원 양/음 방향 중심 Y축 공전. 예상: PDF의 양/음 방향 요구를 r/R로 구분; 같은 방향 재입력은 정지.
7. **시작/거리 변경**: 광원 공전 궤도를 원으로 표시. 예상: 단위 원 선분에 radius_ 배율 적용.
8. **z/Z**: 광원 가까이/멀리 이동. 예상: 1.8~8 범위에서 반지름 조절.
9. **z/Z**: 광원 거리와 궤도 크기 동기화. 예상: 광원 위치와 원 배율이 동일 radius_ 사용; 카메라도 궤도 전체가 보이게 조정.
10. **q**: 종료. 예상: Application::requestClose.

공통 관찰: 셰이더 오류·GL 오류가 없어야 한다. 프레임률이 달라도 시간당 속도는 같아야 한다. 리셋과 방향 전환을 반복해도 객체가 늘거나 잘못된 부모에 남지 않아야 한다.
