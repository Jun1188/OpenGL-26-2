# 실습 24: 사용자 확인

이 폴더 전체를 저장소 밖의 별도 경로로 **복사**한 뒤 `.sln`의 Debug/Release x64를 사용한다. 원본을 이동·삭제할 필요는 없다. 폴더 내부 framework에 소스·헤더·GLM/GLFW·런타임 DLL·셰이더·라이선스가 포함돼 있다. 상위/형제 framework를 참조하지 않는다. Visual Studio C++ 도구·Windows SDK·OpenGL 3.3 지원 드라이버는 시스템 요구다.

빌드·테스트·앱 실행은 에이전트가 수행하지 않았다. 아래 확인은 사용자가 수행한다.

1. **시작/b**: 실습 20 물류 센터·컨베이어·상자 5개 유지. 예상: 기존 경로·검은 사각형 개수 표식·컨베이어 시계 보존.
2. **시작**: 컨베이어 옆 육면체 트럭. 예상: 차체·적재함·운전석·바퀴를 트럭 루트 아래 생성; 중심 (5.5,0,1.0), L자 벨트 세로 구간의 X 바깥에 나란히 배치, 바닥 22×21.
3. **1~5**: 번호에 해당하는 상자 적재. 예상: 현재 월드 위치에서 현재 트럭 슬롯까지 1초 위치 선형보간; 도착 후 부착·적재 확정; 이동 중/적재 후 중복 입력 무시.
4. **V**: 상자 시점/전체 시점 전환. 예상: 전체 시점은 저장·복귀; 지역 카메라 (0,0.775,-1.425)를 각 상자의 최종 월드 변환으로 옮겨 후보 5개를 갱신; 화면 아래 선택 상자 일부가 보이는지 확인.
5. **초기/V**: 처음 선택한 상자 시점은 5번. 예상: viewBox_=4; 배열 인덱스와 상자 번호 구분.
6. **n/N**: 상자 다음/이전 시점. 예상: 1인칭에서만 5→1, 1→5 순환; 번호·entity ID·후보 5개 월드 좌표 출력.
7. **g**: 트럭 출발/정지. 예상: 중간 정지는 방향 유지.
8. **끝점/g**: 바닥 끝에서 정지하고 다음 g에 반대 방향 이동. 예상: 트럭 전체 길이를 고려한 Z=-7.0~9.3 범위; clamp 후 정지·다음 방향 반전.
9. **r**: 전체 리셋. 예상: 장면·적재·부모 관계·트럭 방향·카메라·시계를 초기화.
10. **q**: 종료. 예상: Application::requestClose.
11. **b,+/-,p/P,좌/우**: 기존 실습 20 입력 유지. 예상: 컨베이어 시작/정지, 줌, 투영, 전체 시점 공전.

공통 관찰: 셰이더 오류·GL 오류가 없어야 한다. 프레임률이 달라도 시간당 속도는 같아야 한다. 리셋과 방향 전환을 반복해도 객체가 늘거나 잘못된 부모에 남지 않아야 한다.
